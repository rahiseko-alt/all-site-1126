結論: 「日本好き外国人」が共通して憧れる象徴は 桜 / 神社・寺 / アニメ聖地 / 富士山 / 寿司・ラーメン / 侍・忍者 / 温泉 / 禅・侘び寂び の 8 系統に収束。出身国差は明確で、欧米 = 庭園・武道・禅、東アジア（中・韓・台）= 桜・温泉・アニメ聖地、東南アジア = アニメ聖地・温泉 が高関心。LSKF 命名は「桜 / 鳥居 / アニメ聖地」3 系統から 3 案を再起案（4 音節ローマ字黄金パターン + 和色配色の前提条件と整合）。
  • JNTO「次回したいこと」で 映画・アニメ縁の地訪問 13.0%、満足度 95.4%（数字単独で上位）
  • 桜はアジア圏で写真 SNS 投稿動機が突出、欧米圏は桜 + 歴史・文化の深い体験を志向
  • JFL（日本語学習者）の 約 50% が J-Pop カルチャーを主動機、164 人調査では 80% が影響を実感
  • 欧米市場で「庭園・花」「武道体験」が満足度上位、東アジア・東南アジアで「温泉」「アニメ聖地」「テーマパーク」が上位（JNTO 22 市場調査）

軸 3: LSKF 推奨 3 案（命名 + デザインパッケージ）

案 A: Sakura（桜）

項目内容
命名Sakura（Sa-Ku-Ra・3 音節）/ サブ「Trace the kanji, one petal at a time.」
配色桜色 #FFB7C5 / 薄桜 #F8E8EC / 墨 #3D2C2E（前提資料の「和色空白市場」と完全整合）
マスコット花びら 1 枚（なぞる度に風で舞う UX）
想起情景京都の桜並木、川面に花筏、薄暮の Hanami
SNS ストーリー「桜の季節に始めて、来年の桜までに 1026 字。」春のローンチが拡散性最大
強み全地域共通の憧れ・JNTO アジア圏 SNS 投稿動機と直結・前提リサーチの和色路線にネイティブ適合
弱み競合になり得る単語（化粧品・酒類で既存使用多数）

案 B: Torii（鳥居）

項目内容
命名Torii（To-Ri-I・3 音節）/ サブ「The gateway to kanji.」
配色鳥居朱 #D24545 / 墨黒 #1A1A1A / 金 #C9A961
マスコット狐（稲荷）SD・なぞり成功で鈴が鳴る
想起情景伏見稲荷の千本鳥居、明治神宮の参道、初詣の静謐
SNS ストーリー「漢字を一つ覚えるたびに、鳥居を一つくぐる」進捗を物語化（千本鳥居 = 1000 字達成）
強みJNTO「伝統的祭・儀礼」全地域 1 位と直結。Instagram 映え最強カラー。1026 字構造とゲーミフィケーション親和性が高い
弱み「神社」概念に宗教性を感じる層（一部ムスリム圏）への配慮要
