# 収益モデル+損益計算テンプレート

### これは何か

「どうやって稼ぐか」「いくらで売るか」「いくらかかるか」を1枚にまとめる記入表。毎回ゼロから考えると抜け漏れが出る。このテンプレを埋めれば、収益構造が一目で分かる。

### 5W2H

| 項目 | 内容 |
|------|------|
| **What** | 収益モデル定義+料金設計+コスト構造+損益分岐点の記入テンプレート |
| **Why** | 毎回ゼロから書くと構造がバラつく。統一フォーマットで比較・振り返りが可能に |
| **Who** | エージェントが記入 → マスターがQAで確認・修正 |
| **When** | P0 S5（どうやって稼ぐか決める / いくらで売る+いくらかかる） |
| **Where** | vest1: docs/standards/templates/revenue-model.md → 各プロダクトの docs/ にコピー |
| **How** | 各セクションの{{}}を埋める → 損益分岐点を算出 → マスターに提示 |
| **How much** | 記入30分。QA15分 |
