## 付録A: UIデザインパターン分析フレームワーク

> 模写対象サイトのデザイン体系を分析・記録する際のカテゴリ一覧。
> STEP 2（コンポーネント自動検出）の入力として使える。
> 出典: foodee Session 62-63（SmartNews模写から抽出・汎用化）

| # | カテゴリ | 記録すべき内容 | 典型的なパターン数 |
|---|---------|--------------|-----------------|
| 1 | 画像×テキスト配置 | 全面カバー / 左右分割 / サムネ付き / テキストのみ等の型を列挙 | 4〜6型 |
| 2 | ページ構造のリズム | セクション順序とカード挿入間隔 | 1パターン |
| 3 | テキスト色 | 主テキスト / 補助 / メタ / 反転。黒の透明度段階で整理 | 3〜4段階 |
| 4 | 有彩色 | アクセントカラーの色数と用途 | 1〜2色 |
| 5 | 背景色 | デフォルト白 / セクション信号色 / 暗色パネル | 3〜4段階 |
| 6 | ボーダー | なし（デフォルト）/ 半透明枠 / アクセント枠 | 2〜3種 |
| 7 | 角丸 | なし / 微丸（カード感） / 完全丸（ボタン・タグ） | 3段階 |
| 8 | エフェクト | グラデーション / box-shadow / なし | 1〜2種 |
| 9 | セクション区切り | ライン / 見出し / フィーチャー挿入 / 余白のみ | 3〜4種 |
| 10 | ボタン・リンク | 塗り / 枠 / pill / テキストリンク。色とradiusの組み合わせ | 4〜5種 |

分析結果は `products/{product}/design-patterns.md` に保存し、自治憲法の§デザイン仕様から参照する。
