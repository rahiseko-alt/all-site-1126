# 即死仮説 検証記録テンプレート

### これは何か

「これがウソなら商売が成り立たない」という最重要の前提（即死仮説）を、実際に動くコードで数値検証した結果を記録する表。感覚ではなく「基準値X、実測値Y、差Z%」で合否を判定する。

### 5W2H

| 項目 | 内容 |
|------|------|
| **What** | P0で立てた即死仮説を実装ベースで定量検証し、結果を記録するテンプレート |
| **Why** | 仮説テーブルのresult列を✅/❌に更新するだけでは「何を測って判断したか」が消える。証跡がないと再検証できない |
| **Who** | エージェントが計測・記入 → マスターが判定 |
| **When** | 即死仮説の実機検証時 |
| **Where** | vest1: docs/standards/templates/hypothesis-verification.md → 各プロダクトの docs/ にコピー |
| **How** | 仮説テーブルから即死仮説を抽出 → 計測項目と基準値を設定 → 実装コードで実測 → 合否判定 |
| **How much** | 仮説1件あたり15-30分 |
