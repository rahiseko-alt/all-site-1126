# AIチャットボット価値定義フレームワーク v1.0

> 作成: 2026-04-06 Session 127
> 用途: AI Answer / Dify-Service の出品訴求軸・設計判断の根拠
> 結論: 「顧客のフワッとした要望を、AIが会話をしながら要件定義まで整形して、人間に渡す」

---

## 1. この結論に至る思考回路

### 出発点（間違った訴求）
業種特化出品テキストの初稿は「AIで全部対応します」系の訴求だった。

### 最初の修正
「AIで全部対応 → 対応の質を下げる → 売上リスク」に気づく。
特に宿泊・不動産・士業のように**判断ミスが直接顧客損失につながる業種**では、全AI対応は逆効果。

訴求軸を「人間への引き継ぎ品質」にシフト。

### AI vs IT の住み分け分析
機能を洗い出した時点で気づいた問題：
「個人情報ブロック」「カード番号保護」をAIの強みとして訴求していたが、
これらは**既存の予約システム・フォームがすでにITとして対応済み**だった。

→ ITが管轄済みの領域に介入しても差別化にならない。むしろ精度でITに負ける。

### AIとITの根本的な違い

| | AI | IT（フォーム・予約システム）|
|--|----|----|
| 得意な入力 | 自然言語（曖昧・フワッとした） | 構造化データ（選択肢・数値） |
| 文脈保持 | ◎ 会話を通じて記憶 | ✗ 1問1答 |
| 曖昧さへの対応 | ◎ 解釈・引き出しができる | ✗ 形式エラーになる |
| 精度・再現性 | △ 確率的 | ◎ 決定論的 |
| セキュリティ | ✗ | ◎（PCI DSS等） |

### 介入すべき領域の発見

```
既存ITシステム          AIの担う領域              人間スタッフ
（フォーム・予約）        ↓                        （判断・対応）

構造化入力  ←── ここには入らない

                「フォームに乗らない言葉」
                「曖昧な要望」
                「複数回の会話で引き出す情報」
                「整形→引き継ぎ」
                                    ────→  担当者がすぐ動ける状態
```

---

## 2. 核心価値の定義

**「顧客のフワッとした要望を、AIが会話をしながら要件定義まで整形して、人間に渡す」**

### なぜこれが価値なのか

- **フォームではできない**: フォームは「決まった選択肢」しか受け付けない。「なんとなく広めの部屋で、子供が走り回れる感じの物件」はフォームに乗らない。
- **人間が毎回やるには非効率**: 営業時間外・繁忙期・専門外問い合わせに人間が対応するコストは高い。
- **AIの会話力が活きる**: 曖昧な入力を深掘りし、条件を引き出し、整形する。これは自然言語処理の本質。
- **人間が動ける状態**: 担当者が受け取った時点で「何が必要か」がわかる。ゼロから聞き直す必要がない。

### 競合との差別化

| 競合訴求 | 本製品の訴求 |
|---------|-----------|
| 「AIが全部対応します」 | 「AIが整理して、人間が仕上げる」 |
| 「24時間自動応答」 | 「担当者が動ける状態で朝に届く」 |
| 「問い合わせを削減」 | 「問い合わせの質を上げて渡す」 |

---

## 3. IT住み分けルール（訴求設計の禁止事項）

以下の領域はITがすでに担う。出品テキストで訴求しない。

| 禁止訴求 | 理由 |
|---------|------|
| カード番号・個人情報の技術的ブロック | 予約システム・フォームが対応済み。AIより精度が高い |
| 物件DB検索 | SUUMO・HOME'S等が対応済み |
| 予約・決済処理 | IT管轄。AIは触れない |
| フォームバリデーション | IT管轄 |
| カレンダー予約 | Calendly等が担う |

## 4. 業種別の「フワッとした要望」具体例

### 宿泊業
- 「なんか記念日っぽい感じにしたいんですけど」
- 「子連れで行けますか？アレルギーがあって…」
- 「チェックアウト遅めにできますか？できればですが」

→ 予約ページのフォームには乗らない。AIが会話で引き出し、フロントへ整形して渡す。

### 不動産業
- 「なんとなく広めで、駅から近くて、でも静かな感じで」
- 「今の家賃より少し上でもいいんですが、何かいい物件ありますか？」
- 「離婚することになって、急いで引っ越したくて…」

→ 物件検索フォームに入力できない状態。AIが会話で条件を引き出し、担当者に整形して渡す。

### 士業
- 「なんかトラブルになってしまって、どうすればいいか…」
- 「税金のことで相談したいんですが、どんな書類が必要ですか？」
- 「会社を辞めさせられそうで、これって違法ですか？」

→ 相談フォームに書けない・書き方がわからない。AIが会話で案件を整理し、弁護士・担当者に渡す。

## 5. 出品タイトル軸

**「フワッとした要望を、担当者が動ける状態にして渡す」**

サブ表現候補：
- 問い合わせを「整形」して担当者に届ける
- AIが聞いて整理、担当者が動く
- 受けて・整えて・渡す
