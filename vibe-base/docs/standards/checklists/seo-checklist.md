# SEO設定チェックリスト

### これは何か

Googleに見つけてもらうための設定を、ページごとに1つずつ確認する表。title・description・OGP・JSON-LD・canonicalの5項目×全ページ。設定漏れ=検索に出ない・SNSでサムネが出ない。

### 5W2H

| 項目 | 内容 |
|------|------|
| **What** | 全ページのSEO関連メタ情報を一覧で確認するチェックリスト |
| **Why** | SEO設定は4項目に分かれているが「全ページに設定済み」を確認する記入表がない。漏れ=そのページが検索に出ない |
| **Who** | エージェントが設定・記入 → マスターが確認 |
| **When** | 公開前（title/description, OGP, JSON-LD, canonical） |
| **Where** | vest1: docs/standards/checklists/seo-checklist.md → 各プロダクトの docs/ にコピー |
| **How** | 全ページを列挙 → 5項目を1つずつ確認 → 検証ツールで動作確認 |
| **How much** | 5ページ以下: 30分。10ページ以上: 1時間 |
