最重要結論 — 仮説「ルールではなく道具」は強く支持される
プロは黄金比・三分割・グリッドを ① 設計時の先行スキャフォールド（grid 構築時の比例システム）＋ ② 事後診断（破綻チェック）＋ ③ クライアント説明（post-rationalisation） の三重道具として使う。
名刺の小サイズ（91×55mm）では Markowsky 実験で人は 1.6〜1.7 比を区別できない ことから、厳密な φ 適用は知覚不能。タイポスケール ×1.618 と大ブロック面積比のみが φ の実用領域で、それ以外は optical balance（目視）が最終決定権を持つ。
プロの設計プロセスは「grid で土台 → 視覚で配置 → 黄金比で診断 → 破綻なら修正 → squint test で重心確認 → 引き算で終了」のループ。

軸1. 余白決定の思考回路（mm 単位の意思決定）

プロが余白量を導く6ステップ

  1. 媒体と用途から「基準余白」の当たり — 名刺は外周5mm以上、A4チラシは10mm（ハットツール 2100件超実績）
  2. 比例システムを当てる — Van de Graaf canon（2:3:4:6 = 内:上:外:下）、黄金比、ルート2比をクラシカルキャノンとして配置
  3. グリッド/モジュール選択 — Webは8の倍数（4/8/16/24/32/64px）、印刷は3〜12列モジュラーグリッド
  4. テキスト密度測定 — 紙面のテキスト占有率 30〜50%（余白比率）。luxury寄り60〜70%白、情報密度型30〜40%白
  5. proximity ratio 検査 — グループ内間隔 < グループ間間隔。実証データ：40px以内は89%が「同一グループ」と知覚、120px超は94%が「別グループ」と知覚（NN/g, Wertheimer 1923）
  6. 0.5px〜1mm単位で nudge — Sketch Pixel Grid plugin等は0.25px刻みを可能にする。光学調整が pixel-perfect の本質

「呼吸／間／リズム」の言語化

用語定義（プロの言葉）判断基準
呼吸している（breathing）各要素が隣接要素から十分距離を取り、視覚階層が努力なしに識別できるVignelli：「whitespace は音楽の五線譜のように、無限の構成を生む枠組み」
窮屈（cramped）紙端ぎりぎりまで要素配置、圧迫感・雑な印象ハットツール松田氏
間が抜ける余白過剰で関係性が読み取れない、焦点が定まらないエムハンド「揃える・寄せる・ばらけさせる」3層リズム
リズム8の倍数等のスケール内に全余白が収まるスケール外の数値が混じると視覚的リズムが崩れる

3階層原則の倍率（実務最頻値）

文字間（micro）1.0x（基準）4px

Cieden の "internal ≤ external rule"
同一コンポーネント内余白は隣接コンポーネント間余白以下にする。違反するとグルーピングが破綻する（gestalt proximity が逆転する）。
比率: 最低 1:1.5、理想 1:2

微調整ラウンドの実態 — 「pushing pixels」7段階

希望 → 自信 → 疑念 → 怒り → 諦め → 受容 → 完了 の心理ループ（Web Designer Depot）。**Shift Nudge** という微調整スキル専門教育が商業成立するほど「最後の10%」が技能差を決める。

光学調整（optical adjustment）必須
計算上は中央でも目視で中央に「見えない」ケースが多発。三角形を10px右にずらす、文字を2px小さくするなど、論理と光学の乖離を埋める作業。
「one looks right, the other feels right」 — 数値中心 ≠ 視覚中心

判断力の鍛え方

  1. コピーワーク（copywork） — Da Vinci 以来の古典手法。Smashing「Copy If You Can」（2017）
  2. Dribbbleバケット運用 — 上位作品を pixel for pixel で写経 → twist 加えて rebound
  3. トレース → 模写 → オリジナル の3段階（国内DTP標準） — 『けっきょく、よはく。』『トレース&模写で学ぶデザインのドリル』が定番教材
  4. 日常観察 — 建物・看板・自然の構図を「なぜ整って見えるか」で見続ける
  5. シニアからのフィードバック収集
  6. 意図の言語化練習 — 「なぜこの余白にしたか」を3行以内で説明できる状態を作る

軸2. 黄金比・三分割の実務判断 — 「ルールではなく道具」仮説の検証

黄金比 賛否双方の論拠

立場論者主要主張
批判George Markowsky (Harvard Math, 1992)48種の長方形比較実験で「人は 1.6〜1.7 を見分けられない」。著名作品の黄金比は計測者の恣意
批判Keith Devlin (Stanford 数学教授)「urban legend / design unicorn」。"people think they see the golden ratio... but they can't actually substantiate it"
批判John Brownlee (Fast Company, 2015)既存デザインに後付け円を被せれば何にでも黄金比は現れる（post-rationalisation）
Apple ロゴ原作者 Rob Janoff: "Years later you find out supposedly why you did certain things. And, they are all bullshit"
推奨Darrin Crescenzi (Interbrand NY)φ は「見えない・感じる」組織原理。"intended to be invisible, felt rather than understood"
推奨Müller-Brockmann「秩序のシステム」として grid に組み込むが creativity を縛らない。"One must learn how to use the grid"
推奨Massimo Vignelligrid を "structural guide" として使い "did not allow it to become a restraint"
中立（実務者）99designs / Figma / Inkbot"tool, not a rule — refine するためのもので force するものではない"

「使う／使わない」判断基準

シナリオ使う使わない
情報量が多い・複雑構図黄金スパイラル（視線誘導）—
情報量少・ミニマル三分割（rule of thirds）黄金比は過剰
ロゴ（中〜大サイズ）グリッド検証ツールブランド意図と矛盾するなら無視
密集都市建築—Crescenzi自ら「効果激減」と明言
A系・名刺・複写媒体1:√2（Lichtenberg比）黄金比（半折で比崩れ）
タイポ階層×1.618階段（22→14/15→9pt）×1.5でも可
クライアント提案資料post-rationalisation として—
仮説「ルールではなく道具」の検証結果 → 強く支持（Yes）
ただし「検証道具」よりやや広く、「① 先行スキャフォールド（grid 設定時）＋ ② 事後診断（破綻チェック・クライアント説明）」の二重道具 として運用されているのが実態。
マスター仮説は ② に該当し、これがプロの主流運用に最も近い。

名刺の小サイズ面における適用の限界

  • 物理寸法: 91×55mm の比は 1.655（φ ≈ 1.618）に近いが、Japan Print NYC が "approximately / inexact" と認める
  • 視認距離: 名刺は腕の長さ（30〜40cm）で短時間視認 → Markowsky の「1.6〜1.7 区別不能」が強く効く
  • 情報密度: 氏名・社名・連絡先・QR・ロゴが詰まる小面積で「黄金分割で空白配分」を厳守すると必須情報が入らない
  • タイポ階層の例外: ×1.618 の階段は実用性が高い唯一の確実な φ 応用
  • 結論: 名刺における φ は「タイポスケール」「色面比の大ブロック」までは有効、それ以下の精度では人間が知覚できず、ルール強制の根拠は弱い

代替フレームワーク

比率用途採用文脈
1:√2（Lichtenberg, 1.414）A系用紙、複写・半折を伴う印刷物ISO 216、日本「大和比」（法隆寺）

3:5 / 5:8 / 8:13（Fibonacci近似）φの整数近似実装が楽

「破る」判断基準

  • 習熟前提: "Mastering grids means knowing when to break them"
  • 目的明示: 破壊は communication 目的が明確なときのみ。「ただ崩す」は禁忌
  • 基底構造は必須: "asymmetric designs still maintain a sense of balance"
  • 多数派は遵守: 「majority of the layout adheres to the grid with grid-breaking as a deliberate and controlled deviation」

軸3. カード構成 × 余白の統合思考と自問リスト

カード境界の決定（Chunking）

  • チャンク上限（認知容量）: 古典 Miller 7±2 ／ 新説 Cowan 4±1。プロは「4 を超えたら分割を検討、7 を超えたら必ず分割」を頭に置く
  • Atomic Design 由来の境界判断: 「意味で割れるか／意味で割ったとき各塊が単独で成立するか」
  • NN/g Common Region 原則: 「枠線・背景色は cluttered になりがち。可能なら whitespace 単独で分けろ」。判断順: ①余白だけで分かる → 枠なし ②余白を確保しても紛れる → 背景色（薄） ③それでも分からない → 線

カード間 gap の下限16〜24px = 5〜6mm印刷換算Webflow / Atlassian標準
Z/Fパターンの折れ目に境界視線が自然に区切る99designs

重心・密度バランス（Visual Weight 5要素）

  • 位置（中央から離れるほど重い）
  • サイズ（大きいほど重い）
  • 色（暖色・暗色が重い）
  • テクスチャ（密なほど重い）
  • 方向（vertical elements seem heavier than horizontal ← 縦書きテキストは横書きより重い）
Optical Center（光学中心） — 数値中心の落とし穴
幾何中心ではなく 幾何中心より約 5% 上 が視覚的中心。重心を「数値中心」で取ると沈んで見える。

Squint Test（重心・階層確認の古典技法）

目を細めて細部を消し、ブロック・明暗・大小だけ残す。視線がまず行く場所が焦点、二番手・三番手の順序が視覚階層。Photoshop / Figma の Gaussian blur で代用可（半径5〜10px）。紙面なら腕を伸ばす／2m離れる／写真撮って縮小。

★ プロの自問リスト（設計中に唱える14の問い）

  1. 視線はどこから入ってどこへ抜けるか？（focal point は 1 つに絞れているか）
  2. squint したとき、最重要要素が一番目に見えるか？ 二番目・三番目の順序が崩れていないか？
  3. 8pt grid から外れた値は 1 つもないか？（11px や 13px が混入していないか）
  4. inter-group spacing は intra-group spacing の 1.5 倍以上あるか？
  5. チャンクは 4±1 個以内か？（7 を超えていないか）
  6. このカードは organism として独立して意味が立つか？ 切り出して 1 つだけ提示しても情報として完結するか？
  7. 枠線を消しても余白だけでグルーピングが伝わるか？（線は最後の手段）
  8. optical center（幾何中心より約 5% 上）に重心が乗っているか？
  9. 重さは下にあるか上にあるか、それは意図したものか？（floating か grounded か）
  10. vertical 要素が予想外に重く見えていないか？（縦書き＝重く見える補正をしたか）
  11. 「呼吸」できているか？ 白を「埋めるべき空き」と感じていないか？
  12. 8 歳の子に見せて情報順序が分かるか？（hierarchy の素人テスト）
  13. 手に取って 30cm 離して読めるか？ 視距離での密度は適正か？
  14. 次にいじったら「ましになる」か「悪くなる」か？（後者になった瞬間が完了）

「足し算→引き算」の切替タイミング

  • "why" テスト: 各要素について why を答えられるか？ 答えられないものは即削除
  • 3 回連続でいじって「ましになった感」が無ければ stop（Christian Beck）
  • squint test の結果が 2 回連続で変わらなければ stop
  • Designer Daily 警句: "Knowing when to stop is what turns design from activity into decision-making"

統合分析 — プロの思考回路を1つの意思決定フローに統合

名刺デザイン時の意思決定フロー（プロの思考回路）
  1. 情報整理: 載せる要素を全列挙 → 優先順位付け → 4±1 個のチャンク（カード）に集約
  2. カード境界決定: Atomic Design 基準で「意味で割れるか」を自問。線は最後の手段、余白で分ける
  3. グリッド設定: 8ptグリッドまたは3列モジュラー。外周マージン基準値（名刺は5mm以上）
  4. 比例システム適用: Van de Graaf or タイポスケール ×1.618 を当てる（先行スキャフォールド）
  5. 仮配置: 視覚で要素を置く（grid に従いつつ optical balance 優先）
  6. proximity 検査: internal ≤ external、比率1:1.5以上を確認
  7. 重心確認: Squint test → 焦点1つ、二番手三番手の順序、optical center（中央+5%上）
  8. 診断（破綻チェック）: 黄金比・三分割で計測。ズレ＝整える必要のシグナル（道具運用）
  9. 微調整ループ: 0.5mm単位で nudge、光学調整。心理7段階を回す
  10. 引き算判断: "why" テスト・3回連続で改善なければ stop
  11. 14の自問リストで最終チェック
