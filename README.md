## 移行の留保（2026-11-26）

GitHubコネクタの push は1回あたり2,000ファイル・16MiBまで、かつUTF-8テキストのみで、画像・フォント・3Dモデル等のバイナリは送れません。そのため本体ファイルの完全コピーはこの経路ではできず、現時点では各フォルダにサイトの記録（README）を入れ、ポータルとUI集を実物として公開しています。本体一式の移行は、バイナリを送れる経路（恒平さんのPCからの git push 等）が別途必要です。アプリ系（Next.js等）は静的フォルダでは動かないため、デプロイはフォルダをルートにした個別のVercelプロジェクトが要ります。
