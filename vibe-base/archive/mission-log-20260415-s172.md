### 教訓
- **Haiku は長いコードブロックの全文コピペに失敗する**（独自に要約・再構成する傾向）。Sonnet以上を使う or プロンプトで「diff 0行チェック」を義務化
- **.NET 依存の COM 型 は避ける**: `System.Collections.ArrayList` / `System.Collections.*` は Windows 10/11 デフォルトで動かない。VBA標準 `Collection` / `Dictionary` / `FileSystemObject` を使え
- **VBA の CSV 読み込みは ADODB.Stream 必須**: `Open ... For Input` は CP932 固定で UTF-8 CSV が化ける
- **VBA の MsgBox 文字列は CP932 範囲に限定**: `⚠`/`▶`/`✅`/`❌` 等は化ける。`※`/`【注意】`/`OK`/`NG` を使う
- **`On Error GoTo CleanExit` で無言落ちする設計は危険**: エラー内容を MsgBox で表示する ErrorHandler を必ず持たせる
