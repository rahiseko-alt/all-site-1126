# 設計ドキュメントテンプレート集 v1.0

> **P0（企画）〜P1（開発）で作成する設計ドキュメントのテンプレート集。**
> 該当する工程でプロダクト内の `docs/` にコピーして使う。
> 出典: aiueo/app（PRD/画面遷移/API仕様）、kobaraku（デザインシステム）、review-analysis（ペルソナ/ジャーニー）、microscope（検索設計）

### これは何か

「何を作るか」を開発前に整理するための書類の雛形集。料理で言えば「レシピ」を書くためのフォーマット。材料（機能）、手順（画面遷移）、完成イメージ（デザイン）を事前に決めておくことで、作り始めてから「思ってたのと違う」を防ぐ。

### 5W2H

| 項目 | 内容 |
|------|------|
| **What** | 設計書5種（PRD/デザインシステム/画面遷移/ペルソナ/検索設計）の雛形集 |
| **Why** | 設計なしに開発を始めると手戻りが大きい。書くべき項目が決まっていれば抜け漏れも防げる |
| **Who** | エージェントがコピーして記入 → マスターが確認・承認 |
| **When** | P0（企画）でPRD・ペルソナ。P1（開発）でデザインシステム・画面遷移・検索設計 |
| **Where** | vest1: docs/standards/templates/design-doc.md → 各プロダクトの docs/ にコピー |
| **How** | 必要な種類のテンプレをコピー → `{...}` 部分をプロダクト固有の内容に記入 |
| **How much** | PRD: 2〜3時間。デザインシステム: 1時間。画面遷移: 1〜2時間 |
