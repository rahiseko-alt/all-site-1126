## コミットタイミング（必須）

以下のタイミングで **必ず** コミットを実行せよ：

- 大きな変更（機能追加・設計変更）を完了したとき
- AIエージェント間のバトンタッチ（引き継ぎ）のとき
- エラー階段（モデル昇格：Haiku → Sonnet → Opus）を踏んだとき

```bash
git add . && git commit -m "[AI名]: 内容の要約"
```

**コミットメッセージ例：**
- `[AI名]: 初期スキャフォールドを作成`
- `[AI名]: docs/spec-v1.md に要件定義を追記`
- `[AI名]: エラー解消 - 認証モジュールのリファクタリング`

## コミット前チェックリスト（EXIT前に全項目確認必須）

コミットは「次のエージェントがシームレスに作業を開始できる状態」を意味する。以下を全項目確認してからコミット+EXITせよ。**確認せずにEXITすることは禁止。**

1. `git status` で未ステージのファイルが0であること
2. `git diff --cached` で意図しない変更が含まれていないこと
3. PC表の記載内容が実装と一致していること（差分0）
4. MISSION_LOG Check-outの「変更ファイル」が `git diff --stat` と一致すること
5. 次のエージェントがMISSION_LOGだけで作業開始できる状態であること
   - 未解決事項があれば「次のアクション」に明記
   - 環境依存（npm install必要等）があれば記載
6. 上記すべてOKであることを確認してから、コミット+EXITする

> **背景:** 「EXITして大丈夫か？」の質問に対し80%の割合で漏れが発覚した実績がある。事後質問で気づくのではなく、事前チェックで防止する。
