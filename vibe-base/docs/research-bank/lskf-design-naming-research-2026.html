エグゼクティブサマリー（So What）

LSKF MVP 推奨デザイン方針（横断統合の結論）
  • カラー: 和色基調（藍 #223a70 主・朱 #c93a40 アクセント・白 #fafaf7 ベース）。既存 13 アプリ全てが欧米トーン（緑/青/ビビッド）で和色は完全な空白市場
  • マスコット: 日本固有種採用（柴犬 or 招き猫 or 鯉）。既存マスコットは鰐蟹・フクロウ・鹿・狸で日本固有はゼロ
  • タイポ: 漢字表示=UD デジタル教科書体 N-R / 本文=Noto Sans JP / 英文 UI=Inter
  • ゲーミフィケーション: ストリーク + XP + 進捗リング 3 点のみ。ハート（ライフ）は大人学習者忌避で不採用
  • UI パターン: カード型 SRS 1 画面 1 漢字 + タップ判定（業界収束）
  • 多言語 UI: 英語 + 中国語簡体 + ベトナム語 3 言語 MVP から（既存アプリ 9/13 が英語のみで空白）
  • ダークモード: MVP 必須（業界デファクト）
LSKF 推奨名称候補（5 案・最有力 ★）
  1. ★ Inko（鸚哥）— ローマ字日本語 3 音・「真似て覚える」インコ比喩・マスコット展開容易・WaniKani 黄金パターン踏襲
  2. ★ Kotoba（言葉）— 4 音節・漢字単体ではなく日本語との接点として拡張可能
  3. Fude（筆）— 3 音節・漢字＝筆の直感的連想・書き取り機能と相性
  4. Hanji（造語: Hanzi + Kanji）— 中華圏外国人も含意・4 音節
  5. KanjiKame（漢字亀）— ASO で漢字キーワード獲得 + 亀=長期継続のメタファー
避けるべきパターン
  • 緑系メインカラー → Duolingo / MaruMori と正面衝突
  • フクロウ / 鹿 / 鰐系マスコット → 既存被り
  • 「Kanji ○○」直球命名 → 同名乱立で ASO 差別化不能
  • ハート（ライフ）ゲーミフィケーション → 大人学習者の解約原因
  • SRS のみで機能勝負 → WaniKani / Bunpro / MaruMori と機能正面衝突

統合分析・LSKF 推奨

差別化 3 ポジショニング（被り回避）

① 和色 + 筆文字トーンで視覚独占ゾーンを取る

13 アプリ全てが欧米トーン（緑/青/ビビッド/マテリアル）。日本固有の和色（藍 #223a70 / 朱 #c93a40 / 鶸 #d6c537 / 墨 #1c1c1c）+ 縦書き要素 + 筆文字ロゴで「日本そのもの」を視覚化。サムネ一覧で即判別。外国人が求める「本物の日本」体験と漢字学習の題材と整合。Duolingo 緑・WaniKani 青の正面衝突を回避。

② マスコットは日本固有種（柴犬・招き猫・鯉）

既存マスコットは鰐蟹・フクロウ・鹿・狸でどれも欧米/中華圏的またはキメラ。日本人なら誰でも知っている縁起物動物を起用すれば、アプリ名想起と日本文化学習を同時に満たせる。例: 「Shiba-sensei」（柴犬+巻物）。マスコット不在の硬派 7 アプリにも勝ち、可愛い系 6 アプリとも被らない。

③ 非英語圏ターゲット（中国語・ベトナム語）に振る

LingoDeer/Drops/Duolingo 除く 10 アプリは英語 UI のみ。一方、在日外国人実数の上位はベトナム・中国・韓国・フィリピン・ブラジル（法務省統計）で英語ネイティブは少数派。MVP 段階で英語 + 中国語簡体 + ベトナム語 3 言語 UI を最初から備えれば、巨大空白市場に直接打てる。漢字は中国語話者には部分既知という強みあり。コンテンツ翻訳負荷も「UI 文言+解説」に限定可能。
