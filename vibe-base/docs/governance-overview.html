PC表ルール（8項目） L5-14
  1. 省略禁止: 全行・全列・全フェーズを省略なく提示せよ。抜粋・要約は一切禁止
  2. 照合義務: 進捗に言及するときは必ずPC表照合が先。照合なしに進捗を語ることは禁止
  3. 実物確認必須: 「未確認」「推定」で✅にするな。実物を確認してから記入
  4. 他エージェントの完了報告は、自分で実物確認するまで信用するな
  5. セッション開始時: 対象プロダクトのPC表照合を最初に行う
  6. 完了報告: PC表の#指定が必須
  7. PC表に載っていない作業を勝手に着手するな。 抜けを発見したらPC表への追加を提案し、承認後に着手せよ
  8. PC表連動: タスクの状態を変更したら、対応するPC表を同一コミット内で更新せよ
作業ルール（5項目） L16-22
  • セッション終了時は指示がなくても必ず MISSION_LOG Check-out + コミットを実行する
  • デプロイまでが1タスク。 ローカルテストだけで完了宣言禁止
  • 正式GO前に着手するな。 指示書作成≠実行許可
  • UI変更時は競合調査必須。 モック/コード/移行 形態問わず全適用
  • 1フォルダ = 1エージェント。 自分が開かれたディレクトリ範囲外のファイルを無断で変更するな
