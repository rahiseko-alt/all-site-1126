メッセージクレジットの仕組み（要注意）実データ
  • Sandboxの200クレジットは「one-time（一括付与）」と公式に記載
  • 一方、Difyコミュニティフォーラムでは「毎月カレンダー月でリセットされる」との回答もある
  • 自分のAPIキーを接続すれば、クレジットを消費せずにLLMを使用可能（OpenAI等のアカウントに直接課金される）
  • つまり、無料枠のクレジット = Difyが提供するOpenAI試用枠。自前APIキーなら実質無関係
最重要発見: 自前APIキーでクレジット制限を回避可能実データ
Sandboxプランでも自分のOpenAI/Anthropic APIキーを接続すれば、200クレジット制限はLLM呼び出しに対しては実質的に無効化される。 ただし、アプリ数5個・ナレッジベース50件50MB・チーム1名等の構造的制限は残る。

2. セルフホスト（Docker/Kubernetes）

ライセンスと制限 実データ

  • 完全無料（MIT + Apache 2.0 ライセンス）
  • Community Edition で全コア機能が使用可能（ワークフロー、RAG、エージェント、API）
  • メッセージクレジット制限なし（使用量上限はインフラ性能のみ）
  • アプリ数・ナレッジベース・チームメンバー数に制限なし
  • LLM APIキーは別途必要（OpenAI / Anthropic / Google等から自分で取得）

3. DSLエクスポート/インポート

DSLに含まれるもの 実データ

  • アプリ設定・メタデータ
  • ワークフローのオーケストレーション・ノード設定
  • モデルパラメータ・プロンプトテンプレート
  • ナレッジベースへの接続設定（参照先のみ）

ファイル形式: YAML（DSL v0.6+）

DSLに含まれないもの リスク

  • ナレッジベースのデータ本体（文書・ベクトルデータ） -- 最大の落とし穴
  • サードパーティツールのAPIキー（セキュリティ上、除外）
  • 利用ログ・分析データ
  • Secret型の環境変数（エクスポート時に確認ダイアログが出る）
ナレッジベースのエクスポート機能は未実装実データ
2026年4月時点で、ナレッジベースの公式エクスポート/インポート機能は存在しない。 GitHub Issue #4385 で要望が出ているが、Discussionに転送されたまま未実装。 ワークアラウンドとしてAPI経由でデータを取得するスクリプトを自作する必要がある。

納品への影響: DSLファイルだけではナレッジベースを再現できない。 納品時はナレッジベースの元データ（PDF/テキスト等）を別途提供し、顧客環境で再インデックスする手順が必要。

プラン別の利用可否 推測

公式ドキュメントにプラン別の制限記載なし。DSLエクスポート/インポートはSandboxを含む全プランで利用可能と推定される（アプリ管理機能の一部であり、有料機能として明示されていない）。

4. コスト計算シナリオ

4-A. 開発フェーズ（1案件の試作）

パターンA: Sandbox + 自前APIキー

¥0 + API代

  • Dify Cloud Sandbox: $0
  • 自前のOpenAI APIキーを接続
  • 試作中のLLM呼び出し: 推定200-500回

  • GPT-4oの場合: 約 $1-3（~¥150-450）
制約: アプリ5個まで。並行して複数案件を持つ場合は不足。 ナレッジベース50MB / 50件の制限あり。

¥600-3,600/月 + API代

  • VPS: ¥600-3,600/月
  • 制限なし（アプリ数・ナレッジベース無制限）
  • 複数案件を同時に開発可能
  • 初期構築: Docker Compose で30分-1時間
推奨: 構築代行を本業にするならセルフホスト一択。 月¥600-900で全制限なし。

パターンC: Professional

¥8,850/月 + API代

  • $59/月（~¥8,850）
  • 5,000クレジット/月
  • アプリ50個 / チーム3名
  • ナレッジベース500件 / 5GB
試作目的には割高。 クライアントのCloud環境を使うなら不要。
試作段階での無料枠枯渇リスク: 低い（条件付き）

5. ココナラ出品に向けた戦略的示唆

推奨する開発・納品体制

  1. 開発環境: Hetzner VPS（€3.79-5.59/月）にDifyセルフホスト → 全制限なし・複数案件並行可能
  2. 納品方法: DSLファイル + ナレッジベース元データ + セットアップ手順書 → 顧客のDify Cloud or セルフホスト環境にインポート
  3. 保守契約: セルフホスト構築案件なら月額保守（¥3,000-10,000/月）が自然に成立

7. 調査の限界と未確認事項

  • メッセージクレジットの正確な消費ルール: 1クレジット = 1 LLM呼び出しが基本だが、GPT-4系で20クレジット消費との情報もある。モデルごとの消費レートは公式に明確な一覧表がない リスク
  • Sandboxクレジットのリセット: 公式は「one-time」と記載するが、フォーラムでは「毎月リセット」との回答。自前APIキーを使うなら実質無関係だが、矛盾は未解決 推測
  • ココナラでのDify構築代行の相場: 日本語検索では具体的な出品価格データを取得できず。別途ココナラ直接調査が必要
  • Enterprise料金: 要問合せのため未確認
  • トリガーイベントの定義: ワークフローのトリガー（Webhook/スケジュール等）の具体的な消費ルールは未確認
