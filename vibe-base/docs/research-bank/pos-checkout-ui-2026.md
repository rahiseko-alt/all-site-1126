## 横断比較サマリー

### レイアウト構成
- 全社（Square/Airレジ/スマレジ/Toast）が**左右2ペイン**構成
  - 左: メニューグリッド / 商品選択
  - 右: チェック（伝票）詳細 + 小計 + 合計
- diniiのみモバイル1カラム（LINE Mini App）

### 小計・税・割引の表示
- 右パネル下部にスタック表示が業界標準
- 表示順: 小計 → 割引 → サービス料 → 税 → 合計
- 税計算は商品ごとの税率設定に基づく自動計算

### 支払種別選択のUI
- 「お会計」ボタン → 支払い画面に遷移（全社共通フロー）
- 主要決済手段は大きなボタンで表面露出（現金/カード/電子マネー）
- 二次的手段は「その他」に格納
- テンキーは画面右側に大きく配置（スマレジ方式が参考）
- Fast Cash（定額ボタン: ¥1000, ¥5000, ¥10000）はToast方式が優秀
- 混合支払い（現金+カード等）対応が標準

### 割り勘/個別会計
| 方式 | 対応社 | UI |
|------|--------|-----|
| 商品別分割（By Item） | Square, Airレジ, Toast | チェックボックスでアイテム選択→新チェックに移動 |
| 席別分割（By Seat） | Square, Toast | シートトラッキング連動 |
| 均等分割（By Amount） | Square, Toast | 人数指定→均等割り |
| セルフ個別決済 | dinii | テーブル内各自のスマホから個別支払い |

- Airレジ: チェックボックス式（商品選択→個別会計）が最もシンプル
- Square: 3方式ボタン選択（By Item/Seat/Amount）が最も柔軟

### 色使いの傾向
| 社 | 基調色 | アクセント | テーマ |
|-----|--------|-----------|--------|
| Square | 白+黒 | 黒/青 | ライト |
| Airレジ | 白+ブルー | 青 | ライト |
| スマレジ | 白+グリーン | 緑 | ライト |
| Toast | ダーク(濃紺) | オレンジ | ダーク |
| dinii | 選択可 | 店舗カスタム | ダーク/ライト |

### POS UI設計原則（業界ベストプラクティス）
1. タッチフレンドリー: 最低44x44px、主要ボタンはさらに大きく
2. 3タップルール: あらゆる機能に3タップ以内でアクセス
3. 色によるグルーピング: 関連コントロールを色で示す
4. 高コントラスト: 異なる角度・距離からの視認性確保
5. 頻用ボタン強調: よく使うボタンは大きく、稀なボタンは小さく
6. 認知負荷最小化: 全機能を出さず、頻繁タスクに絞る
7. 割り勘は計算をシステムが行い、スタッフ入力は分割数と支払方法のみ
8. 確認画面の明確さ: オンスクリーンレシートとして表示
