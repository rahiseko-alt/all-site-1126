### Go/No-Go判断に必要なQA（マスターへ）

以下の情報が揃わないとGo/No-Go判定できません。

1. **ターゲットは誰か？** 自分用の執筆効率化ツールか、外部ユーザーへの販売を想定しているか
2. **収益モデルは何か？** SaaS課金か、ツール販売か、単なる自社ユーティリティか
3. **現状の使用頻度は？** `bot-activity.log` に実績あり？自分で使って価値を感じているか
4. **Wikipedia投稿実績はあるか？** 生成された下書きが実際にWikipediaに掲載されたことはあるか

> **Opusへ:** Q1〜Q4への回答次第でGo/No-Go/棚上げが決まります。マスターに確認を促してください。
