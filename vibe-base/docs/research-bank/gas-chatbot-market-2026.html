5. 空白地帯分析 — 「チャットbot × GAS」の交差点

現状の市場構造

GAS自動化市場チャットbot市場
ココナラ1,152件（カテゴリ230）462件（カテゴリ772）
主要技術GAS + SheetsDify / LINE API / ChatGPT API
GASの役割主役（自動化の本体）裏方（オプション+5,000円）
bot要素通知送信（Slack/LINE/CW）が付随AI応答・RAG・FAQ
単価3,000〜15,000円が主流5,000〜50,000円
空白地帯: 「GASをバックエンドにしたチャットbot専門サービス」は現時点でほぼ存在しない。GAS出品者はbot機能をオプション扱い、チャットbot出品者はGASを意識していない。
具体的に:
  • LINE Bot + GAS + Sheets（予約管理/FAQ/通知）をパッケージ商品化している出品者はたま＠SE（Dify併用）のみ
  • ChatWork Bot + GAS 専門出品 = ゼロ
  • Google Chat Bot = Workspace制限で市場なし
  • Slack Bot + GAS 専門出品 = ほぼゼロ（通知機能として含まれるのみ）
注意: 空白＝チャンスとは限らない。空白の理由が「需要がない」可能性もある。
需要の証拠:
  • CWに「LINE通知ツール開発（GAS or Python）」5-10万円の案件が存在
  • ココナラで「GAS連携」オプションが+5,000円で売れている
  • たま＠SE のDify+GAS+LINE出品が63件販売（需要あり）
  • ランサーズの「スプシベースFAQチャットbot」に実績あり
需要は存在する。ただし現状は「GAS自動化のついで」or「チャットbotのついで」として消化されており、専門カテゴリとして成立するかは未証明。

ピボット後の位置づけ案

前提: マネタイズ大作戦のタイムライン（4月1円→5月5万→...）から逆算すると、4月中に出品可能な状態にする必要がある。GAS×botの「パッケージ商品」は、Dify-Serviceの梅（DSL納品5,000円）と同じ速度感で立ち上げられる候補。
切り口内容Dify-Serviceとの違い
A. LINE Bot + GAS パッケージ LINE公式アカウント自動応答 + Sheets記録 + GAS通知。予約bot/FAQ bot/通知botのテンプレート販売 Dify不要。GAS+LINE APIで完結。より軽量・安価
B. ChatWork/Slack Bot + GAS 業務自動化 ChatWork/Slackに定期通知・集計bot。日報・勤怠・タスク通知 AIなし。定型通知に特化。企業向け
C. GAS WebApp + チャット通知 パッケージ Webフォーム（投稿/アンケート/集計）+ チャット通知。旧GWS-Evalの技術を流用 Difyは使わない。Google Workspace完結

Dify-Serviceとの棲み分け

Dify-ServiceGAS×Bot（新）
AI要素あり（RAG/LLM）なし or 軽量（ChatGPT API経由）
技術基盤Dify + DockerGAS + Google Workspace
顧客のインフラVPS or Dify CloudGoogleアカウントのみ
導入ハードル中（Docker知識 or Cloud契約）低（GASコピーで即動作）
月額コストあり（VPS/API）なし（GAS無料枠内）
