# Wix Wizard CSS計測表（動画フレーム分析）

> ソース: 画面録画 2026-03-29 003504.mp4（1362x604px, 94sec）
> 手法: ffmpeg 1fps全体抽出 + 10fps遷移部分抽出 + sharp pixel分析
> 注意: 録画解像度がブラウザ実寸と異なる可能性あり。比率ベースで記載

## 4. アニメーション・エフェクト

### 4a. 導入 → Step1 遷移（全体フェード）

| タイミング | 内容 | 推定duration |
|-----------|------|-------------|
| t+0.0s | 導入画面（浮遊テンプレ＋ダイアログ）が表示中 | — |
| t+0.0〜0.5s | 全要素がopacity 1→0にフェードアウト | ~500ms |
| t+0.5〜1.5s | 完全ブランク（#f5f3f1のみ） | ~1000ms hold |
| t+1.5〜2.0s | Step1がopacity 0→1でフェードイン + テンプレカード再配置 | ~500ms |
| **合計** | | **~2.0s** |

**イージング推定:** ease-in-out（フェードの入り/抜けが緩やか）

### 4b. Step間遷移（ローディング＋カラースウィープ）

| タイミング | 内容 | 推定duration |
|-----------|------|-------------|
| t+0.0s | 現ステップのコンテンツがフェードアウト | ~300ms |
| t+0.3s | 「次のステップをカスタマイズしています」テキスト出現 | ~200ms fade-in |
| t+0.5s | プログレスバー開始（カード上端、左→右） | 全長~2.5s |
| t+0.5s | テキストカラースウィープ開始 | — |
| t+0.5〜3.0s | カラースウィープ: 紫(#4040ff)が左→右に文字を撫でる | ~2.5s |
| t+1.0s | 浮遊テンプレカード再登場（四隅からスライドイン） | ~1.0s |
| t+3.0s | 全テキスト黒に戻る + プログレスバー完了 | — |
| t+3.0〜3.5s | コンテンツフェードアウト → 次ステップフェードイン | ~500ms |
| **合計** | | **~3.5s** |

### 4c. カラースウィープ詳細（10fpsで確認）

```
t2-010 (t+1.0s): 「次の」= 紫、残り = グレー(未着色)
t2-015 (t+1.5s): 「次のステップ」= 紫→黒遷移中、「を」に紫到達
t2-020 (t+2.0s): 「カスタマ」に到達、1行目ほぼ黒化完了
t2-025 (t+2.5s): 「イズして」に到達、2行目進行中
t2-030 (t+3.0s): 全文字 黒。スウィープ完了
t2-035 (t+3.5s): テキスト全体が紫に再変化（2周目 or フェードアウト前演出）
```

**スウィープ速度:** 約12文字/2.5s = ~5文字/秒
**実装推定:** `background-clip: text` + `linear-gradient` のposition animationまたはCSS `@keyframes`で`color`をcharacter単位で遅延

### 4d. 浮遊テンプレカード

| 属性 | 値 |
|------|-----|
| 枚数 | 4-6枚（ステップにより変動） |
| サイズ | 約80-120px |
| 配置 | 四隅 + 両サイド（カード外の余白領域） |
| 傾き | 各カード5-15°回転（3Dパースペクティブ） |
| 影 | drop-shadow（浮遊感） |
| ステップ遷移時 | 散開（画面外へ飛ぶ）→ 別配置で再収束（~1s） |
| 導入画面 | より大きく、中央寄り配置 |

### 4e. プログレスバー

| 属性 | 値 |
|------|-----|
| 位置 | カード上端（内側） |
| 高さ | 2-3px |
| 色 | 紫〜青グラデーション |
| アニメーション | 左→右、linear、~2.5s |
| 背景（未到達部分） | #e5e5e5（ライトグレー）|

## 5. UXパターン

| パターン | 詳細 |
|---------|------|
| 1問1画面 | 各ステップで1つの質問のみ。認知負荷を最小化 |
| タグ選択UI | テキスト入力 + おすすめタグのpill表示。タップで入力補完 |
| AI演出 | 「カスタマイズしています」= AI処理中の印象を与える待機画面 |
| スキップ導線 | 右上に常時「ダッシュボードへスキップ→」 |
| 戻る導線 | フッター左に「←戻る」 |
| プログレス | バー（連続）。ドットではない |

## 6. 計測の制約

| 項目 | 制約 | 対策 |
|------|------|------|
| font-family | フレームから特定不可 | Wixのデフォルト = Madefor（独自書体）推定 |
| font-weight | ピクセルから推定困難 | 見出し: 600-700、本文: 400推定 |
| letter-spacing | 計測不可 | — |
| line-height | テキストブロック高から間接推定のみ | 見出し: 1.3-1.4推定 |
| border-radius正確値 | ピクセル目視 | 16-20px |
| easing関数 | 1fps/10fpsでは粗い | ease-in-out推定 |
| transition-duration正確値 | ±100ms程度の誤差 | — |
| DPI/zoom | 録画時の設定不明 | 比率ベースで記載 |
