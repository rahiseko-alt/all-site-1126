## 起動方法
```
cd build && python3 -m http.server 8901
# http://localhost:8901/ を開く（ES Modules のため file:// 直開きは不可。単一ファイル版は直開き可の場合あり、要確認）
```
URLパラメータ: `?mode=screensaver`（メニューなし）、`?color=white` / `?color=true`、`?word=abc` または `#abc`（単語固定）。「f」キーでフルスクリーン。
