# プロジェクト昇格手順

> 本ファイルはルート CLAUDE.md の SOP索引から参照される運用手順書である。
> 単独では規範力を持たない。CLAUDE.md 本体の原則が常に優先される。

---

## 原則: 昇格 = 移動（コピーではない）

外部リポジトリ（Misfits.PJ 等）から vibe-base にプロジェクトを移管（昇格）する場合、以下の手順を **すべて** 実行せよ。

昇格後は **vibe-base にのみ** フォルダが存在し、移動元からは完全に消えている状態を最終形とする。

---

## 手順

1. **移動先の準備:** `products/[project-name]/` にファイルを配置する
2. **移動元の削除:** 移動元リポジトリの該当フォルダを削除する（`rm -rf`）
3. **移動元の記録更新:** 移動元の memory.md・プロジェクト一覧の状態を「vibe-base に昇格済み」に更新する
4. **移動先の記録更新:** vibe-base の `memory.md` プロジェクト状況テーブルに追加。確定インフラ欄にURLがあれば追記
5. **ルール切り替え確認:** 昇格後は **vibe-base の CLAUDE.md のみ** に従う。移動元のルールには従わない
6. **技術的検証:**
   - `.gitignore` が存在するか（なければ作成）
   - manifesto 違反（alert() / confirm() / prompt() 等）がないか横断チェック
   - ビルドステップがある場合はビルド通過を確認
   - デプロイ設定（vercel.json 等）が正しいか確認
7. **コミット:** 移動元・移動先それぞれでコミットする

---

## 旧版の退避

昇格時にプロジェクトの旧版が存在する場合は `archive/[project-name]-[旧版識別名]/` に退避する。

> **理由：** 2026-03-06 の Aiueo LP 昇格時に「コピーしただけで移動元に残留」「移動元のプロジェクト記録が未更新」「.gitignore 欠落」「alert() 残留」が発生。手順を明文化し再発を防止する。
