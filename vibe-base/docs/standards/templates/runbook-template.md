## §1. アラート種別と通知先

| 種別 | 検知条件 | 通知先 | 初期判定時間 |
|------|---------|--------|-------------|
| P0 致命 | サービス全停止 / 決済不整合 / データ漏洩 | マスター（電話+メール） | 即時 |
| P1 重大 | 主要機能停止 / 性能 50% 低下 | マスター（メール） | 30 分以内 |
| P2 軽微 | 一部機能停止 / 性能 25% 低下 | マスター（メール） | 翌営業日 |

## §2. 即時対応フロー

1. 検知 → 影響範囲特定（エラーログ / DB 状態 / 外部依存）
2. 停止判断（ロールバック可否）
3. 実行（30 分以内 P0 ロールバック or maintenance mode）
4. 第 1 報（ユーザー告知、状況不確定でも「調査中」で出す）
