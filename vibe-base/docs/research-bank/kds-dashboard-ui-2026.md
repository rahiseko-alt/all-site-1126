# KDS / 管理画面 UIパターン調査レポート

> 調査日: 2026-03-14
> 目的: デザインモックアップ仕様書の参考資料

## 1. Square KDS

### KDS画面

**カードレイアウト**
- Android専用アプリ（iOS廃止済み）
- 設定 > Layout からテキストサイズ・列数・チケットレイアウトをカスタマイズ可能
- 21.5インチ MicroTouch スクリーンで最大18チケット同時表示
- レイアウトは「多数チケット一覧表示」vs「全アイテム表示の詳細チケット」を選択可能
- 列数は設定画面で切り替え（具体的に2/3/4列等を選択）

**注文カードの情報配置**
- チケットヘッダー（バナー）: 注文番号、テーブル/顧客名
- タイマー表示: 経過時間をヘッダー部に表示
- 品目リスト: アイテム名、数量、モディファイア
- カテゴリー別色分け表示対応

**完了操作**
- **チケット一括完了**: チケット上部バナーをタップ
- **アイテム単位完了**: 個別アイテムを直接タップ
- **Undo**: 完了後3秒以内に再タップで取消可能
- **リコール**: 「Completed」タブ内のチケット下部「Recall」をタップで復元
- バンプバー（外部ハードウェア）接続にも対応

**ステーション分離**
- **Prep（調理ステーション）**: アイテム単位の作業向け。担当品目のみ表示
- **Expo（エクスペダイター）**: 全チケットの俯瞰ビュー。全Prepステーションの進捗を統合表示
- 完了範囲設定: 「Complete for all devices」/「Complete only on this device」を管理画面で設定
- Expo完了時は全Prep+Expoデバイスに伝播

**色使い・緊急度**
- **タイマーアラート**: 正常→黄色（Warning）→赤色（Critical）の3段階
- 黄色/赤色のしきい値（分数）は管理画面で個別設定可能
- アクセントカラー: オレンジ (#f75a38)
- CTA/ボタン: ブルー (#006aff)
- 新規チケット到着音の ON/OFF 設定あり

**テーマ**
- **ダークモード対応**: 背景 #1d1d1d〜#000
- **ライトモード**: 背景 #fafafa〜#fff
- ダークモード時、選択チケットはライターな背景シェードで強調
- ライトモード時、選択チケットはダーカーな背景シェードで強調

### 管理画面（Square Dashboard）

**サイドバーナビゲーション**
- Home / Invoices / Items & Menus / Orders / Customers / Reports / Settings / Account / Support
- レストラン版では Items が「Items & menus」に変更

**ダッシュボード主要ウィジェット**
- Sales Summary パネル（売上、返金、取引量）
- Activity Feed（最近の取引一覧）
- レストラン固有レポート: セクション別売上、キッチンパフォーマンス

**メニュー/商品管理**
- Menu Group によるカテゴリ整理（色、サイズ、配置カスタマイズ）
- 複数ロケーション横断メニュー管理

**レスポンシブ対応**
- モバイル: シングルカラム、padding 20px
- タブレット (718px+): 2カラム、padding 30-40px
- デスクトップ (1024px+): マルチカラム、padding 60px+
- ボタン: border-radius 5px、ホバーステート付き

## 2. Airレジ キッチンモニター

### KDS画面

**カードレイアウト**
- iPad（タブレット）専用アプリ
- 2つの表示モード:
  - **テーブル別表示**: テーブルごとに注文をグルーピング（横画面推奨）
  - **注文時間順表示**: 注文受付順にカードを時系列配置
- 2つの業務モード:
  - **キッチン業務モード**: 調理スタッフ向け
  - **ホール業務モード**: 配膳スタッフ向け

**注文カードの情報配置**
- テーブル番号/席番号をカードヘッダーに表示
- 注文品目リスト（カテゴリー色付き）
- 同一商品の複数注文は横に合計数を集約表示
- 注文からの経過時間を記録・表示

**完了操作**
- **商品タップ**: 個別商品をタッチで「調理済み」→配膳画面で青色表示に変化
- **「すべて配膳済」ボタン**: 同一注文送信の全商品を一括完了
- **配膳済み取消**: 誤操作時、タッチで未配膳に戻し可能
- 2ステップフロー: 調理済み → 配膳済み

**ステーション分離（調理場振り分け）**
- 管理画面で「調理場」を複数定義
- 商品カテゴリーごとに担当調理場を割り当て
- 各キッチンモニターで表示する調理場をフィルタ設定

**色使い・緊急度**
- カテゴリーごとに色設定可能（カテゴリーカラーがカードに反映）
- **提供アラート**: 目標提供時間を商品ごとに設定
  - 注意時間超過 → **オレンジ色**に変化 + 「着手アラート」表示
- **配膳完了**: 青色表示
- 目標提供時間を基準に自動並び替え（調理しやすい順）

**テーマ**
- ライトテーマベース（公式にはダークテーマ未提供）
- 白背景にカラーアクセント

### 管理画面（Airレジ オーダー + Airメイト）

**ナビゲーション構造**
- AirID → ご利用サービス管理 → Airレジ オーダー の階層
- サイドメニュー: モバイルオーダー / キッチンモニター設定 / メニュー管理
- 上部: AirID（アカウント名）・店舗名表示 → マイアカウント/店舗基本情報

**ダッシュボード（Airメイト連携）**
- リアルタイム当日売上（会計済み + 未会計客数からの想定売上自動算出）
- 満席率/出勤スタッフ情報のリアルタイム表示
- 売上・コスト目標シミュレーション
- 客数・客単価の目標逆算機能
- 固定費入力 → 月末着地利益予想
- ABC分析、集客分析（客層別/曜日別）、人件費分析（カレンダー形式）
- ウィークリー/月次レポート自動作成
- 自動営業日報（コメント機能付き）

**レストランボード（予約管理）ダッシュボード**
- 予約数 / 総客数 / 予約コース / 予約経路 / 目標実績

**レスポンシブ対応**
- Airメイト: スマートフォンダッシュボード対応
- 管理画面: PCブラウザ/タブレット対応

## 3. スマレジ

### KDS画面（スマレジ キッチンモニター）

**カードレイアウト**
- ブラウザベース（Safari/Chrome）でiPad等タブレット端末推奨
- スマレジ・ウェイター連携で注文データをリアルタイム受信
- 注文一覧をリスト/カード形式で表示

**注文カードの情報配置**
- 注文メニュー名・数量
- 注文からの経過時間
- テーブル番号

**完了操作**
- メニューごとの調理状況をステータス変更（調理済み/配膳済み）
- 完了した注文は履歴として再呼び出し可能

**ステーション分離**
- キッチンモニターを複数台設置可能
- モニターごと（Webブラウザごと）に表示するカテゴリーを設定
- カテゴリーフィルタリングでステーション分離を実現

**色使い・緊急度**
- 注文から一定時間経過でアラート表示
- アラート色による視覚通知

**テーマ**
- ライトテーマベース（ブラウザベースのためOSのダーク/ライト設定には非依存）

### 管理画面（スマレジ管理画面）

**サイドバーナビゲーション（左メニュー）**
- **商品**: 商品一覧 / 商品登録（新規登録）/ 部門管理 / グループコード
- **売上分析**: 日別売上 / 月別売上 / 曜日別売上 / 時間帯別売上 / 商品別売上 / 部門別売上 / グループコード別売上 / 店舗別売上 / スタッフ別売上 / 端末別売上 / 客層別売上 / 取引タグ別売上
- **取引**: 取引一覧 / 取引履歴
- **会員**: 会員管理
- **在庫**: 在庫管理
- **設定**: 基本設定（店舗設定、税率、レシート等）

**ダッシュボード（トップ画面）**
- 本日の売上サマリー（純売上、粗利益）
- 今月の売上サマリー
- ダッシュボード初期表示のカスタマイズ可能
- VIEWER機能: 管理画面以外（アプリ等）からの売上確認

**商品管理**
- 商品名、価格、商品コード、商品画像、カテゴリー、税率、原価の入力
- CSV一括インポート対応
- 部門・グループコードによる階層管理

**設定画面**
- 管理画面 > 設定 > 基本設定 からアクセス
- 店舗情報、税設定、レシート設定、端末設定、スタッフ権限

**レスポンシブ対応**
- 管理画面: PC/タブレットブラウザ対応
- POSアプリ: iPad/iPhone対応
- タブバー表示項目のON/OFF設定可能（販売業務/仮販売/取引履歴/精算/在庫管理/データ収集/商品情報/会員情報/店舗）

## 4. Toast KDS

### KDS画面

**カードレイアウト**
- 2つの表示モード:
  - **Classic（Dynamic）View**: チケットが左から右に動的に配置。テキストサイズに応じてチケットサイズが変動
  - **Grid View**: 固定グリッドレイアウト。チケットサイズ変更ダイアログで表示数を制御
- テキストサイズ変更でチケットサイズと同時表示数が連動
- 画面構成: 上部=ヘッダー、中央=チケットエリア、下部=ナビゲーション/ページインジケーター
- 横スワイプでページ送り（残りチケットの閲覧）

**注文カードの情報配置**
- **チケットヘッダー**: テーブル番号/ゲスト名、注文タイプ、経過時間
- **ヘッダー色**: チケット経過時間に応じて自動変化（白→黄→赤等）
- **品目リスト**: メニュー名、数量、モディファイア
- **モディファイア表示**: Grid Viewでは赤文字（背景色未設定時）
- **席番号表示**: Grid View対応（2025年追加）
- **コース情報**: 前コース情報の表示対応

**完了操作**
- **タッチスクリーン**: チケットをタップで Fulfill（完了）
- **バンプバー（外付けハードウェア）**: 水平/垂直レイアウト切替可能
  - FULFILL ボタン: 選択チケットを完了
  - RECALL LAST: 直前に完了したチケットを復元
  - 番号ボタン(1-10): 該当番号チケットを選択（ダブルタップで即完了）
  - ページ送り矢印ボタン
- **Expediter画面**: アイテムごとに緑チェックマーク表示。全アイテム完了でチケット消失

**ステーション分離**
- **Prep Station（調理ステーション）**: ルーティングルールで品目カテゴリーを割り当て
- **Expediter Station**: 全Prepステーションのチケットを統合表示
  - 1 Expo / 2 Expo のワークフロー対応
- **ルーティングルール**: メニューカテゴリー → ステーションの紐付け
- **コースペーシング**: コース順序に基づく火入れ(firing)制御

**色使い・緊急度**
- **チケットヘッダー色**: 経過時間ベースで段階的に変化
- **カスタムカラー**: メニューアイテム/モディファイアに個別色を割り当て可能
  - ライトモード用パレット ⇔ ダークモード用パレット（自動対応選択）
- **アレルギー対応**: モディファイアに色を割り当て、健康上の注意を視覚化
- **Expo画面**: 全品完了チケットのヘッダーが**緑色**に変化
- **アイテム完了**: 個別アイテム横に緑チェックマーク

**テーマ**
- **ダークモード / ライトモード**: 両対応
- ダークモード: 選択チケットはライターシェード背景で強調
- ライトモード: 選択チケットはダーカーシェード背景で強調
- カラーパレットは Light/Dark 間で自動マッピング

### 管理画面（Toast Web）

**ナビゲーション構造**
- Toast Web（ブラウザベース管理画面）でメニュー編集/従業員管理/レポート閲覧
- サイドバー/トップナビゲーション構成

**ダッシュボード（Reporting Dashboard）**
- Weekly Overview レポート
- Net Sales / Gratuity / Tips / Total Guests
- Table Turn Time
- サービスタイプ別内訳
- 支払い方法別内訳
- 個別アイテム売上 / サーバー別売上 / クレジットカード種類別

**レポート機能**
- 全デバイス対応（スマホ/タブレット/PC）のスキャン可能レポート
- 時間帯指定でのフィルタリング
- 顧客行動分析（来店頻度、平均注文額、人気メニュー）

**レスポンシブ対応**
- ブラウザベースで全デバイス対応

## 5. Lightspeed Restaurant

### KDS画面（KDS 2.0）

**カードレイアウト**
- 2つのレイアウトモード:
  - **Direct Line View**: チケットを上から下まで全長表示。チケット下に余白が残っても全情報を一目で確認
  - **Equal View**: 画面を均等分割してスペースを最大活用。ただしチケットが切り詰められる可能性あり
- 2つの表示密度:
  - **Full View**: Collection code / Server / Type / Covers を各行表示
  - **Condensed View**: 上記4項目を2行2列にアイコンで圧縮表示
- 2つの運用モード:
  - **Ticket Mode（FSR向け）**: 注文単位でチケット表示。左=Pending、右=Ready
  - **Production Mode（QSR向け）**: 同一品目を集約。品名の頭文字で4列にソート

**注文カードの情報配置**
- トグルで表示/非表示を切替可能な項目:
  - Customer / Order ID / Number of Customers / Server / Type / Floor / Order Source / Pickup Time
- チケットヘッダーにこれらの情報を配置
- 品目リスト（調理指示付き）

**完了操作**
- **タップ**: 個別アイテムをタップで完了（Started → Ready）
- **全チケット完了**: 全アイテム完了時、チケットが**緑色**に変化 → Completed タイムスタンプ記録
- **長押し操作**: ステータス選択メニューを表示
  - Canceled（キャンセル）
  - On hold（保留 = **茶色**表示）
- **Bump**: 注文カードを画面からクリア → アーカイブ（所要時間データ記録）

**ステーション分離**
- Production Center（生産センター）を管理画面で複数定義
- メニューアイテム → Production Center の紐付け
- 各KDSデバイスに表示する Production Center を設定

**色使い・緊急度**
- **時間経過グラデーション**: 緑（0分）→ 赤（50分以上）まで段階的に変化
- **調理指示の色分け**:
  - Warning（オレンジ + 三角アイコン）: アレルギー情報
  - Addition（緑 + プラスアイコン）: 追加アイテム
  - Removal（赤 + 禁止アイコン）: 除去アイテム
  - Comment（青 + 吹き出しアイコン）: その他コメント
- **全品完了**: チケット全体が**緑色**
- **保留中**: **茶色**

**テーマ**
- **ライトテーマ / ダークテーマ**: 設定画面で切替可能
- KDS設定画面で Color theme > Light / Dark を選択

### 管理画面（Back Office）

**サイドバーナビゲーション（左メニュー）**
- **Home**: ダッシュボードに戻る
- **Reports**: Sales Summary / Sales Report / Staff Reports 等
- **Menu**: メニュー管理 / アイテム管理 / 生産指示 / 会計グループ
- **POS**: デバイス設定 / 接続コード / ユーザー / ユーザーグループ
- **Integration Hub**: サードパーティ連携（オンラインオーダー/予約等）
- **検索バー**: Cmd+K / Ctrl+K でクイック検索

**ダッシュボード**
- 売上サマリー（グラフ/チャート形式）
- Best Sellers（人気商品ランキング）
- Top Payment Methods（支払方法ランキング）
- 期間フィルタ: Today / Yesterday / This week / This month / This Year
- 異なる期間の売上比較

**Sales Report ダッシュボード**
- 売上パフォーマンスのグラフィカル概要
- 期間比較
- 詳細レポートへのドリルダウン

**レスポンシブ対応**
- Back Office: ブラウザベースでデスクトップ/タブレット対応
- Lightspeed Pulse App: モバイル向け簡易ダッシュボード

## 6. dinii（ダイニー）

### KDS画面（ダイニーキッチンディスプレイ）

**カードレイアウト**
- iPad専用アプリ（App Store配信）
- 3つの表示形式から選択可能:
  - **注文単位表示**: 1注文=1カード
  - **注文状況表示**: ステータスでグルーピング
  - **注文順表示**: 時系列リスト
- 各キッチンポジション（従来プリンタ箇所）にディスプレイを設置
- プリンタ伝票との並行利用も可能

**注文カードの情報配置**
- 卓別（テーブル番号）表示
- メニュー別表示
- 時間別表示
- 提供時間の正確な記録・表示
- モバイルオーダー/ハンディからの注文情報をリアルタイム反映

**完了操作**
- タッチ操作でステータス変更
- 紙伝票不要のデジタル一覧管理
- 注文が一気に入っても一覧で管理可能

**ステーション分離**
- キッチンの各ポジションごとにディスプレイを設置
- ポジション別にフィルタリング表示

**色使い・緊急度**
- テーブルごとの滞在時間に応じた自動アラート表示
- 最終注文からの経過時間に基づく追加注文促進アラート
- 提供時間の可視化による改善サイクル

**テーマ**
- 公式情報ではダークモード/ライトモードの明示なし
- iPhone/iPad ライクなクリーンUIを標榜

### 管理画面（ダイニーダッシュボード）

**ナビゲーション構造**
- ブラウザベース管理画面（dashboard.self.dinii.jp）
- 本部管理 / 店舗管理の階層構造
- 店長 / マネージャー / 本部管理者ごとに権限・表示を分離

**ダッシュボード主要ウィジェット**
- 全店舗リアルタイム売上
- 客単価
- ABC分析（商品分析）
- 店舗ごとの比較 / エリアごとの分析
- 顧客属性別分析（LINE連携データ活用）:
  - 新規客に人気の商品ランキング
  - リピーターに人気の商品ランキング
  - 常連客が必ず頼むメニュー

**メニュー管理**
- リアルタイムメニュー変更
- 「本日のおすすめ」登録
- おすすめ商品のトップ表示
- 動画付きメニュー表示（客単価向上施策）
- 顧客属性に合わせたメニュー表示の出し分け

**CRM / 顧客管理**
- LINE公式アカウント連携
- カスタマイズクーポン配信
- 来店頻度 / 好みのメニュー / 性別 / 最終来店日 / 来店回数のトラッキング
- ダッシュボード上で配信・分析を完結

**レスポンシブ対応**
- ダッシュボード: ブラウザベース（PC/タブレット）
- POS: タブレット + スマートフォン

### デザインモックアップへの推奨事項

**KDS画面**
1. **ダークテーマを基本に**: Square/Toast/Lightspeedが対応。キッチン環境では視認性が高い
2. **3段階タイマーアラート**: 正常(白/グレー) → 注意(黄/オレンジ) → 緊急(赤) が業界標準
3. **時間グラデーション**: Lightspeed方式（0分=緑→50分=赤）が最も直感的
4. **完了操作はタップ+バンプ**: チケットバナータップ(一括)とアイテムタップ(個別)の二階建て
5. **Expo/Prep分離**: 調理ステーションとエクスペダイターの2層構造が標準
6. **Undo/リコール**: 誤操作防止は必須。Square方式の3秒猶予が参考になる
7. **カード情報の優先順位**: テーブル番号(最上部) > 経過時間(目立つ位置) > 品目リスト(本体) > モディファイア(インデント)
8. **Condensed View**: Lightspeed方式のアイコン圧縮表示はスペース効率が良い

**管理画面**
1. **左サイドバー固定**: 全6社が左ナビゲーション構成
2. **ダッシュボードKPI**: 本日売上 / 客数 / 客単価 / 人気商品の4ウィジェットが最低限
3. **期間フィルタ**: Today/Yesterday/This week/This month/Custom の5段階
4. **クイック検索**: Lightspeed方式の Cmd+K がUX向上に有効
5. **レスポンシブ**: タブレット2カラム / デスクトップ3+カラム が標準
