はじめてでも、この通りにやれば完成します

AIが毎日、SNS投稿を自動で作って積んでおく

Buffer（バッファー：予約投稿ツール）と連携して、SNSへの投稿を自動化するしくみと、その作り方を「パソコンが苦手な人」目線で最初から最後まで案内します。

🧭
やることは大きく2つだけ。AIの「作業部屋」を1回作る → 「毎日◯時に働いて」とセットする。あとはあなたのパソコンの電源が切れていても、勝手に動き続けます。

📘この資料の使い方：アカウントを何も持っていない前提で、「作り方」の手順を上から実行すれば完成します。画面操作はできる限りClaudeが代行し、あなたはパスワードやGoogleの「許可」など本人しかできない所だけ。青い文字（このようなリンク）はクリックで開きます。各ステップの緑チェックで「できたか」を確認しながら進めてください。

01

まず何をするの？ ── たとえ話で

むずかしい言葉の前に、やりたいことのイメージを。

ひとことで言うと 「AIに毎日SNSの投稿を作らせて、予約投稿ツール（Buffer）に“積んで”おく」 こと。Bufferは投稿を預かってくれる係で、時間になったら代わりに投稿してくれます。流れは3つだけ。

✍️

① AIが作る

決めたルールどおりに、AIが投稿の文章（と画像）を毎日つくります。

→
🗂️

② Bufferに積む

作った投稿を「順番待ちの列」に入れて預けます。まだ表には出しません。

→
📣

③ Bufferが出す

予約の時間になったら、BufferがX・Threads・Instagramへ自動で投稿します。

💡
ここが大事：AIの仕事は「作って預ける」まで。実際にSNSへ出すのはBufferの役目です。だからこのしくみを “キュー（＝順番待ちの列）補充型” と呼びます。
02

裏側の流れ ── 1本道の絵

上から下へ、順番に起きています。灰色の小さい字はIT用語の正式名なので、今は読み飛ばしてOK。

  1. ⏰
    目覚まし時計が鳴る（毎日 昼12時）クラウドRoutine が決まった時刻に自動で起動
  2. 🏠
    AIの「作業部屋」が立ち上がる環境: カギ（トークン）＋ 外線電話（api.buffer.com への通信許可）
  3. 📥
    必要な材料一式を取り込むGitHub の「あなたの空リポジトリ」を clone（コピー取得）
  4. ✍️
    AIが投稿を書く（X 2本・Threads 2本・IG 1本）ルール（プロンプト）に従って本文と画像を生成
  5. 🗂️
    Bufferの「順番待ちの列」に積むapi.buffer.com に addToQueue で登録
  6. 📣
    時間になったらBufferが自動で投稿Buffer → X / Threads / Instagram
  7. 🧾
    結果を記録して終わり成功／失敗を result.json に書き出し
03

言葉の意味 ── これだけ知ればOK

手順で出てくる言葉を、身近なものにたとえて説明します。

GitHub github
プログラムやファイルを保管しておくネット上の倉庫サービス。なぜ要る？→ AIがこの倉庫（あなたの空リポジトリ）を作業場所として使うため。無料アカウントが必要。※このガイドで唯一「Googleで続ける」が使えないサイトです。
環境 environment
AIの「作業部屋」。中にカギ（トークン）と外線電話（通信許可）を置いておく設定のまとまり。なぜ要る？→ AIが安全に材料と道具を持って作業する場所だから。
Routine routine
「目覚まし時計」。決めた時刻にAIを起こして、決めた仕事をさせるしくみ。なぜ要る？→ 毎日あなたが操作しなくても自動で回すため。
トークン token
Bufferに入るための「カギ／通行証」になる秘密の文字列。なぜ要る？→ これが無いとAIがBufferを操作できません。人に見せてはダメ。
キューに積む addToQueue
「順番待ちの列に入れる」。すぐ投稿せず、Bufferの配信待ちリストに追加すること。
クラウド cloud
Anthropic（アンソロピック）が用意したネット上のコンピュータのこと。なぜ便利？→ 自分のパソコンが切れていても、そこで動き続けるから。
04

文章は誰が書くの？

じつは「文章を作る機械」は無くて、AIがルールを読んでその場で書いています。

text ── X / Threads

ルールに沿ってAIが執筆

「どんな役で・どう書くか」を決めた指示（プロンプト）に従い、AIが毎回その場で文章を作ります。

  • 役：中小企業の社長さん向けの「AI活用アドバイザー」
  • 40〜140字・ていねいな「ですます」・呼びかけは「御社」
  • URL・絵文字・ハッシュタグ・大げさな言葉は使わない
  • 最後は「御社の◯◯は？」と問いかけて締める
image ── Instagram

Instagramは画像が必須

Instagramは文字だけでは投稿できない決まりなので、カード画像を用意して一緒に添えます。

  • 画像を作り、ネット上の公開URLとして添付する
  • 画像の置き場所は今のところ仮ぐみ（今後きちんと固定予定）
🧠
つまり：文章を作っているのはAI本体、その“書き方の説明書”がプロンプトです。だから「文章を変えたい」＝「プロンプトを直す」ことになります（→ 手順07）。
05

Routine（ルーティン）って何？

この自動化の心臓部。よく「Coworkのこと？」と聞かれますが、別物です。

クラウドRoutineとは、claude.ai/code（Claude Code on the web）にある「決まった時刻に自動で動かすタイマー」のこと。時間になるとネット上のAIが自動で起き上がり、決めた作業をこなします。Anthropicのクラウドで動くので、あなたのパソコンの電源は関係ありません。

クラウドRoutine これを使う

claude.ai側のネット上で定時に自動実行。設定はクラウドに保存され、パソコン無しで動き続ける。Bufferの自動投稿はこちら。

Cowork 別物

パソコンのアプリ側のしくみで、予定はパソコン内に保存される。今回のBufferの自動投稿とは別系統です。混同しないよう注意。

作り方 ── 上から順に

アカウントを何も持っていない前提で、ゼロから作ります。🟢 緑＝Claudeが画面操作を代行／🟠 オレンジ＝あなただけができる認証・入力（パスワード・確認コード・Googleの「許可」・カギのコピー）。新規登録は原則「Googleで続ける」を使います。

🪄
いちばん楽な始め方（二画面方式）：下のプロンプトをコピーして、Claude Codeの入力欄に貼るだけ。この資料を見ながら、Claude Codeにも同じ流れでナビさせるので迷子になりません。画面操作はできる限りClaudeが代行し、あなたはパスワードやGoogleの「許可」など本人しかできない所だけ行えばOK。
🪄 全部おまかせプロンプト（これ1つでOK）
BufferとSNSの自動投稿をゼロからセットアップしたいです。私はアカウントを何も持っていない前提で、パソコン操作も得意ではありません。手順書（ナビ資料）はこちら： https://claude.ai/code/artifact/237dbdb4-0054-4011-9ef7-d2d0421fa752 この資料を開けるなら読み、下の流れで私をナビしてください。ルール： ・画面操作はできる限りあなた（Claude）が代行してください。私が行うのは、パスワード・二段階認証コード・Googleの「許可」ボタン・カギ（トークン）のコピーなど、本人しかできない所だけにしてください。 ・新規アカウントは、その画面に「Googleで続ける／Sign in with Google」があれば必ずそれを使ってナビしてください（Googleアカウントを共通の入口にします）。無い場合だけメール登録。 ・私が操作する所は「どの画面のどこを押すか」を1ステップずつ指示し、私が「できた」と言うまで次に進まない。 ・各ステップの最初に、資料のどの番号か（例：手順⑥）を教える。 【この順でナビして】 ① Googleアカウントを用意（無ければ作成。これを共通ログインに使う） ② claude.ai に登録（「Googleで続ける」） ③ GitHubに登録（Google非対応なので②と同じGoogleのメールで） ④ Claude Code と GitHub を接続 ⑤ 私用の空リポジトリを作って選ぶ ⑥ Bufferに登録（「Googleで続ける」）してパーソナルAPIキー（トークン）を取得 ⑦ 環境を作成（環境変数 BUFFER_API_TOKEN と、通信許可 api.buffer.com） ⑧ お試し：投稿を1本、下書きでBufferのキューに追加 ⑨ 毎日12時（日本時間）に自動実行するRoutineを登録 まずは私が今どこまで出来ているか（Googleアカウントの有無など）を1つずつ聞いて、①から順にナビを始めてください。トークンの値は絶対に出力しないでください。

あなた・初回だけ

  4. メールに届く確認コード（数字）を入力する → 完成
✅
できたか確認：GitHubにログインし、画面右上に自分のユーザー名が出ていればOK。

自分用の「空っぽの倉庫（リポジトリ）」を作って選ぶ

Claudeが操作

Claudeが作業する場所として、あなた専用の空のリポジトリを1つ用意します。Claudeに頼めば作成まで代行できます。中身は空でOK（作業はClaudeが後から入れます）。

📋 空リポジトリを作ってもらう
私のGitHubに、SNS自動投稿用の空のリポジトリを1つ作ってください（名前はおまかせ。例：sns-auto）。作成できたら、そのリポジトリ名（ユーザー名/リポジトリ名）を教えてください。
  1. 作れたら、claude.ai/code の入力欄の下のリポジトリ選択ボタンで、その自分のリポジトリを選ぶ（手動作成なら github.com/new でも可）
  2. モードは 「Accept edits」のままでOK
✅
できたか確認：リポジトリ選択欄に、自分で作ったリポジトリ名が表示されていればOK。

Bufferに登録して「カギ（トークン）」を取る

Claudeが操作許可・コピーはあなた

予約投稿ツール Buffer に登録し、AIをBufferにつなぐ通行証＝パーソナルAPIキー（トークン）を取ります。登録は「Googleで続ける」で。画面はClaudeが案内、あなたはGoogleの許可と、最後のキーのコピーだけ。

Buffer をひらく buffer.com
  1. Bufferの登録画面で 「Continue with Google（Googleで続ける）」 を選び、①のアカウントで登録
  2. 開発者ページ（developers.buffer.com）で パーソナルAPIキーを発行（Generate）
  3. 表示された文字列（40文字前後）をコピーし、メモ帳など安全な所に一時保存
🔑 発行ボタンが見つからない時の裏ワザ
  1. Bufferにログインしたまま F12 で「開発者ツール」を開く
  2. 「Network（ネットワーク）」タブを選び、画面を少し操作する
  3. 一覧から api.buffer.com 宛ての通信を1つクリック → 「Headers」→ Authorization: Bearer の後ろの文字列をコピー
🚫
大事：「開発者アプリを新規登録」する古い方法は受付終了。取るのは “パーソナルAPIキー1個” だけ。このカギはチャットやメールに貼らない・人に見せない。
✅
できたか確認：40文字前後の文字列を1つコピーできていればOK（中身は見せず、手元に控えるだけ）。

AIの「作業部屋（環境）」を作る

あなた・値の貼付は本人

GitHubをつなぐと「環境を作る」フォームが出ます。Claudeが手順を指示しますが、カギ（トークン）の貼り付けだけは秘密なので、あなた自身が行います。次の3つを入れて、最後に 「Create environment」を押します。

  1. Name（名前）：好きな名札。例 buffer-auto
  2. Environment variables（環境変数）の欄に、⑥で取ったカギをこの形で1行入れる：
    BUFFER_API_TOKEN=ここにカギを貼る
    ※ クォート（" "）で囲まない。囲むと壊れます。
  3. Network access（通信の許可）：「Custom」を選ぶ → 出てきた欄に api.buffer.com と入れる → 「Also include default list…」にチェック
🔒
カギはこの環境変数の中だけに置きます。専用の金庫機能はまだ無いので、環境を編集できる人には見える点だけ覚えておいてください。
✅
できたか確認：環境の設定に BUFFER_API_TOKEN が登録され、通信許可に api.buffer.com が入っていればOK。

まず「お試し」で1本だけ動かす

Claudeにお願い

いきなり毎日にせず、手で1回だけ動かして確かめます。まずは表に出ない「下書き」で安全にテスト。下のプロンプトをコピーして、Claude Codeの入力欄に貼るだけ。

📋 その1：下書きでお試し
環境変数 BUFFER_API_TOKEN を使って、Buffer に投稿を1本、下書きとして追加してください。手順は次の通りです。 1) まず https://api.buffer.com にGraphQLで問い合わせ、私のチャンネル一覧を取得し、X（旧Twitter）のchannelIdを特定する。 2) 中小企業の経営者向けのX投稿を1本、日本語で作成する（40〜140字・ですます調・二人称は「御社」・URL/絵文字/ハッシュタグ/誇大表現は使わない・末尾は「御社の◯◯は？」型の問いかけで締める）。 3) createPost mutation を https://api.buffer.com にPOSTする（headers: Authorization: Bearer $BUFFER_API_TOKEN、input: mode=addToQueue, schedulingType=automatic, saveToDraft=true）。 実行後、成功/失敗と、作成した本文を教えてください。トークンの値は絶対に出力しないでください。
🧪
下書きが無事できたら、次のプロンプトで本番の予約に切り替えます（saveToDraft を外すだけ）。
📋 その2：本番のキューに積む
先ほどと同じ手順で、今度は下書きではなく本番のキューに積んでください（saveToDraft を外す）。Bufferのキューに予約登録できたら、post.id と status を教えてください。トークンの値は絶対に出力しないでください。
✅
できたか確認：AIが「成功しました」と返し、Bufferの管理画面に下書き（または予約）が実際に現れていればOK。

毎日自動にする（目覚まし時計をセット）

Claudeにお願い

お試しが成功したら、最後に下のプロンプトを貼るだけで自動化は完成です。

📋 毎日自動にする
今のこの「投稿を生成して Buffer のキューに追加する」処理を、毎日 昼12時（日本時間 JST）に自動実行するクラウド Routine として登録してください。時刻は UTC に換算してください（12:00 JST = 03:00 UTC）。登録できたら、トリガーID（trig_… で始まるもの）を教えてください。
🕛
時刻の世界標準時（UTC）への変換も登録もClaude Codeがやってくれます。時間を変えたければ「毎日◯時」の数字を書き換えるだけでOK。
🎉
これで完成！翌日から、あなたが何もしなくても「投稿を作る→Bufferに積む→時間になったら配信」が毎日回ります。
07

あとで内容を直したい時

初心者がいちばん間違えやすい所です。

投稿の“書き方の説明書”（プロンプト）は、倉庫（GitHub）の中ではなく、Routine本体に保存されています。だから倉庫のファイルを直しても投稿は変わりません。変えたい時は、下のプロンプトを貼って、〔　〕の中を書き換えて送ります。

📋 内容を変更する
Buffer自動投稿のRoutineの今のプロンプトを見せてください。そのうえで、次のように直してください：〔ここに変えたい内容を書く。例：投稿の文字数を200字までにして／IGの画像を毎回新しく生成するようにして〕

今ちゃんと動いているか不安なときは、これで結果を確認できます。

📋 動いているか確認する
Buffer自動投稿の最新の実行結果（result.json）を確認して、直近の投稿がちゃんと成功しているか、失敗しているかを教えてください。
⚠️
よくある誤解：「倉庫の説明書ファイルを直した＝反映された」ではありません。倉庫の中の説明文は古いことがあるので、実際の動きを変えるにはRoutine本体を直します。上のプロンプトなら、Claude Codeが正しい場所（Routine本体）を直してくれます。
08

注意とエラー対処

安全に使うための注意と、詰まった時の早見表です。

安全のために

カギ（トークン）は絶対に見せない

  • チャットやメール、倉庫（GitHub）に値を貼らない
  • 置き場所は環境変数だけ（専用の金庫はまだ無い）
  • 環境を編集できる人には見える前提で扱う
無料プランの制限

順番待ちは10件まで

  • 無料プランは配信待ちを10件までしか積めない
  • 超えると LimitReachedError というエラーになる
  • Instagramの画像置き場は今のところ仮ぐみ

エラー早見表（AIがこう返してきたら）

出たメッセージ意味（やさしく）どうする
UnauthorizedErrorカギが違う／入ってない環境の BUFFER_API_TOKEN を入れ直す
LimitReachedError順番待ちが10件で満杯たまった投稿を減らす／上限内にする
ネットワークエラーBufferに電話がつながらない通信許可に api.buffer.com が入っているか確認
InvalidInputError入力のどこかが間違い投稿先の指定や入力値をAIに確認してもらう
