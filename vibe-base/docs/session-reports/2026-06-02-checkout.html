★ デザイン品質の思想（最重要・次回の design 作業で必ず適用）

マスターから叩き込まれた核心。フォント/配色をいじる前に骨格と思想を発明せよ。

  • 金太郎飴の正体 = 見た目でなく骨格が毎回同じ（hero→section→footer の縦スクロール）。AIは統計平均（Inter/紫青グラデ/中央3カード/均一余白）に逃げる。
  • 品質＝発明の階層: ①訴求の本質を一言 → ②ユーザーに何を感じさせるか → ③到達2秒以内に、文字でなく"感覚"で伝える → ④見たことないが理解しやすい表現 → ⑤実装。形式/次元/操作で発明し、フォント色は最後の味付け。
  • 参照実物を必ず自分の目で確認してから作る（b4bを"見ずに当てた"のは失敗。八面体＝マスターの正解見本＝"ページでなく触れる体験"）。
  • 最新技術を使え（可変フォント/font-variation kinetic・GSAP・Three.js/WebGL・SVG歪み）。素CSSだけは品質頭打ち。
  • サブを使え（最大5体・裏で）。実装系は背景でも Write 通った（テキスト返却fallbackも用意済）。

フリノバの確定コンセプト＝「仲間」。卒業しない"居場所"（入会金一回で一生＝関係を切らせない料金設計が証拠）。案件はランサーズで足りる＝コアでない。市場根拠: フリーランス1,303万人/孤独40.7%/相談相手なし64.3%/案件の74%が人脈経由（[出典は feed/research ログ]）。冒頭2秒で文字ゼロで「ここに来れば仲間ができる」を感覚で伝えるのがヒーローの使命。
