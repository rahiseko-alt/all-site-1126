# Draggable Liquid Tube

## 概要
シリンダー状の温度計やチューブを模したUIにおいて、液面をドラッグ操作で上下させることができるインタラクティブなアニメーションです。

## 技術的ポイント
1. **SVGマスクとグラデーション**
   - `<linearGradient>` と `<clipPath>` を活用し、液体のグラデーションカラーがチューブの枠内に収まるようにマスク処理しています。
2. **GSAP Draggable & InertiaPlugin**
   - 横にあるドラッガー（スライダー）を `Draggable` で動かせるようにし、指を離したあとの慣性スクロールを `InertiaPlugin` (旧 ThrowProps) で実現しています。
3. **動的な SVG アニメーション**
   - GSAP 3の `gsap.to()` と `modifiers` を使用し、ドラッガーの位置（`y`）に追従して、液面の高さ（SVGの `y` 座標）や液体の波打ち（`x`軸のループ移動）をリアルタイムに更新しています。
   - `gsap.getProperty` を使ってリアルタイムに要素の座標を取得し、弾性のあるイージング（`elastic.out`）で追従させることで、液体らしい「揺れ」を表現しています。
