#5 クライアント納品メッセージ — md vs html

比較

md テキスト版
docs/templates/client-credentials.md
  • 47行。プレーンテキスト
  • ココナラトーク・LINE等のテキストチャネルにコピペして送る用
  • {{変数}} 方式で置換箇所を明示
  • 値の取得方法テーブル付き
  • Aiueo固有の文言（「Aiueoモバイルオーダーシステム」）
html 印刷版
docs/templates/client-credentials.html
  • 117行。印刷対応CSS付き
  • ブラウザで開いて直接編集（contenteditable）→ 印刷して紙で渡す用
  • Apple風デザイン。ステップUIと情報カード
  • @media print で印刷レイアウト最適化済み
  • Aiueo固有の文言（「Aiueo モバイルオーダーシステム」）

分析

md版とhtml版は 用途が違う。md=テキストチャネル送付用、html=印刷渡し用。重複ではなく、同じ情報の配信チャネル違い。
両方ともAiueo固有の文言が入っているが、vest1（docs/standards/templates/）にコピー済みのものはmd版のみ。
現状vest1にあるのはmd版のコピー。html版はvest1未登録。
推奨: 両方残す 用途が異なる（テキスト送付 vs 印刷渡し）。vest1のmd版を汎用化済みなので、html版も汎用化してvest1に追加が理想。ただし急ぎではない
#6 QRコード発行ガイド — md vs html

比較

md テキスト版
docs/templates/client-qr-guide.md
  • 49行。プレーンテキスト
  • テキストチャネルにコピペして送る用
  • {{変数}} 方式
  • 手順4ステップ+補足
  • Aiueo固有（Ordering/Kitchen/Cashier/Daddy）
html 印刷版
docs/templates/client-qr-guide.html
  • 181行。印刷対応CSS付き
  • ブラウザで直接編集→印刷用
  • ロール一覧テーブル（色分けバッジ付き）
  • 手順5ステップ+Tip+FAQ 3件
  • Aiueo固有（Ordering/Kitchen/Cashier/Daddy）

分析

#5と同じパターン。md=テキスト送付用、html=印刷渡し用。用途違いなので重複ではない。
ただし QRコード発行はAiueo固有機能（QRでロール認証する仕組み自体がAiueo特有）。他プロダクトでQRガイドが必要になるケースは限定的。
vest1に置く意味は薄い。Aiueo固有品として products/aiueo/ 配下に移す方が適切。
推奨: 両方残すが移動 Aiueo固有品。docs/templates/ から products/aiueo/docs/ に移動して、vest1対応表からは除外が妥当

#8 料金設定ガイド — docs/ vs hearing-bot/

比較

共有正本
docs/pricing-guide.md
  • 「全プロダクト共有資料」と明記
  • CLAUDE.md §3 参照資料テーブルに登録済み
  • 出典: マスター提供 app_pricing_guide_v2.docx
  • hearing-botで初回適用と記載
hearing-bot版
products/hearing-bot/pricing-guide.md
  • 冒頭に「共有版（正本）: docs/pricing-guide.md」と注記済み
  • 内容は共有版と同一（差分なし）
  • hearing-bot CLAUDE.md から直接参照されている
  • 元はここで作られ、後にdocs/に共有資産化された

分析

hearing-bot版の冒頭に「共有版（正本）: docs/pricing-guide.md（本ファイルから共有資産化済み）」と書いてある。
つまり 共有資産化は完了しているが、元ファイルが残っている状態。内容は同一。
hearing-bot CLAUDE.md が pricing-guide.md を直接参照しているので、削除する場合はCLAUDE.mdの参照パスを ../../docs/pricing-guide.md に変更する必要あり。
推奨: hearing-bot版を削除 共有資産化済みの旧元ファイル。hearing-bot/CLAUDE.md の参照パスを docs/pricing-guide.md に変更し、hearing-bot版を削除
