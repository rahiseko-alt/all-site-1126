# クチコミ分析AI 競合調査レポート

> **調査日:** 2026-03-14
> **目的:** 国内外のクチコミ管理・レピュテーション管理ツールを調査し、機能ギャップと開発優先度を特定する
> **対象市場:** 飲食店（カフェ・居酒屋・個人店〜小規模チェーン）向けクチコミ分析・返信ツール

---

## 1. 横断比較サマリー

### 市場の現状

- **AI返信はコモディティ化:** ほぼ全ツールがChatGPT/生成AI連携のAI返信を搭載済み。「AI返信できます」だけでは差別化不可能
- **MEO（Map Engine Optimization）がセット:** 国内ツールの大半がMEO順位計測を主力に、口コミ管理を付随機能として提供
- **口コミ促進が高需要:** QRコード・SMS・アンケートによるレビュー獲得機能が標準装備化しつつある
- **深い感情分析は空白地帯:** 大半のツールは「ポジネガ判定」止まり。テーマ抽出・QSCA分析・トレンド把握ができるのは口コミコムとBirdeyeのみ
- **個人店向け低価格帯は手薄:** 主要ツールは月額5,000〜50,000円。¥980で深いAI分析を提供できれば明確なポジション確保が可能

## 2. 個社分析

### 2-1. 口コミコム（株式会社mov）

**ポジション:** 国内最大手。店舗DXプラットフォーム
**導入:** 28,000店舗超（サブウェイ、ピザハット等）
**資金:** 累計50億円超調達（Coral Capital, KDDI等）
**料金:** 非公開（エンタープライズ向け要問合せ）

**対応プラットフォーム（31サイト連携、口コミ19サイト — 国内No.1）:**
- Google / 食べログ / Yahoo!プレイス / ホットペッパー / ぐるなび / Retty / TripAdvisor
- 大衆点評（中国。国内唯一の一括管理）
- Booking.com / Expedia / Agoda / 楽天トラベル / じゃらん / 一休.com / 出前館 / アソビュー!

**主要機能:**
- 店舗情報一括管理（全連携サイト自動反映、特許取得済み）
- AI口コミ分析（QSCAスコア: Quality/Service/Cleanliness/Atmosphere）
- AI返信サポート（Google・食べログ対応）
- 競合店舗の口コミ分析
- クーポン一括配信、アンケート、多言語情報発信
- 都道府県別・FC別の細分化レポート

**当社との比較:**
- **脅威:** 機能の広さと深さで圧倒的。食べログ公式連携は参入障壁
- **隙間:** エンタープライズ向け→個人店は手が出ない。価格非公開→透明性で差別化可能
- **学ぶべき点:** QSCA分析の枠組み、競合口コミ分析の概念

**参照:** https://kutikomi.com/

### 2-2. Hoshitorn / 星トルン（株式会社エフェクチュアル）

**ポジション:** Google口コミ特化の管理ツール
**導入:** 4,000店舗（2021年時点）
**料金:** 無料（閲覧のみ）/ パーソナル ¥7,000 / エンタープライズ ¥50,000〜

**対応プラットフォーム:** Google専用

**主要機能:**
- ダッシュボード（口コミ状況グラフ、店舗間ランキング）
- AIネガポジ判定（スコアリング）
- 半自動返信（テンプレートベース。生成AIではない）
- 口コミ促進（一括依頼送信、QRコード生成）
- 改善ミッション管理（ネガティブ口コミ→PDCAアクション）
- 2025年4月「Location Connect」にリニューアル

**当社との比較:**
- **脅威:** 無料プランで個人店参入障壁が低い。PDCAサイクル管理は独自
- **隙間:** AI分析の深さが浅い（ポジネガのみ）。返信はテンプレ→AI生成で差別化
- **学ぶべき点:** QRコード口コミ促進、改善ミッション管理のUI

**参照:** https://effectual.co.jp/lp/hoshitorn/

### 2-3. MEOチェキ（株式会社トライハッチ）

**ポジション:** 国内MEOツールトップシェア。口コミ管理は付随機能
**導入:** 75,000店舗以上
**料金:** フリー ¥0 / エントリー ¥3,278〜 / プレミアム ¥5,478〜 / プロ ¥16,500〜

**口コミ関連機能（星カクトくん）:**

- 口コミ促進（SMS/QRコードでアンケート→高評価者をGoogle投稿画面へ誘導）
- 口コミ自動返信（テンプレート設定）
- SNS同時投稿（GBP→Instagram/Facebook/X/LINE一括配信）

**当社との比較:**
- **脅威:** 75,000店舗の圧倒的シェア。MEO+口コミのセット提供
- **隙間:** 口コミ分析の深さは限定的。MEOが主力で口コミ分析は副次的
- **学ぶべき点:** 口コミ促進フロー（アンケート→高評価者を投稿画面へ自然誘導）

**参照:** https://meo.tryhatch.co.jp/meocheki/

### 2-4. Gyro-n Review（ジャイロン）

**ポジション:** 口コミ管理×AI返信×販促活用の一気通貫ツール
**料金:** 基本¥0〜（SMS別途¥20/通）

**主要機能:**

**当社との比較:**
- **脅威:** キキコミ特許、医療対応で差別化済み
- **隙間:** 飲食特化ではない。感情分析は浅い
- **学ぶべき点:** アシスト型AI返信のUXフロー（通知→ワンタップ→編集→投稿）

**参照:** https://www.gyro-n.com/review/

### 2-5. STOREPAD（イクシアス）

**ポジション:** 飲食店向け店舗DX一元管理。国内最多23媒体連動
**料金:** 初期¥5,000 + 月額¥5,000/店舗

**主要機能:**
- 23媒体連動（MEO/口コミ/SNS）
- AI口コミ分析→返信案を複数パターン提示
- AI自動分析で店舗課題抽出
- 多言語AI翻訳

**当社との比較:**
- **脅威:** 飲食特化で立ち位置が近い。媒体数が多い
- **隙間:** ¥5,000/店舗は個人店には高め。AI分析の詳細は不明
- **学ぶべき点:** 飲食特化のカテゴリ設計

**参照:** https://storepad.jp/

### 2-6. Birdeye（米国、参考）

**ポジション:** G2 No.1。エージェント型AIでレビュー管理を自動化
**料金:** $299〜$449/月。日本未展開

**主要機能:**
- 200以上のサイトからリアルタイム収集
- Review Response Agent（感情・緊急度・画像解析→ブランドトーン返信を自動生成）
- ルールベースワークフロー分岐（低評価→店長承認ルートへ）
- Review Generation Agent（SMS/メールで自動レビュー依頼）
- 多言語返信生成

**学ぶべき点:**
- 「Agent」概念（分析Agent / 返信Agent / 収集Agent の分離設計）
- ルールベースのワークフロー分岐
- ブランドボイス学習による返信の一貫性
- 画像を含むレビューの解析

**参照:** https://birdeye.com/

## 3. クチコミ分析AIの現状と差別化ポジション

### 現在の強み

| 強み | 詳細 |
|------|------|
| AI分析の深さ | Gemini 2.5 Flash によるセンチメント分析（-1〜1スコア）+ テーマ抽出。大半の国内競合より深い |
| AI返信のトーン調整 | 丁寧/親しみ/謝罪の3トーン。国内で対応しているのは少数 |
| 圧倒的低価格 | ¥980/月。競合最安帯の1/3〜1/5 |
| セルフサービス | 営業不要。登録→即利用。個人店のハードルが最も低い |
| 技術基盤 | Next.js + Neon Postgres + Gemini。スケーラブルかつ低コスト |

### 致命的ギャップ（全競合が対応、当社なし）

| 機能 | 影響 |
|------|------|
| 口コミ新着通知 | 返信の即時性がクチコミ管理の生命線。通知なしでは「管理ツール」と呼べない |
| 評価推移グラフ | 「改善が数字に現れているか」を可視化できない |
| レポートエクスポート | 経営者がチームに共有できない |
| 認証/ログイン | 現在はURLを知っていれば誰でもアクセス可能 |

### 差別化可能な領域

| 領域 | 競合状況 | 当社の狙い |
|------|---------|-----------|
| QSCA分析 | 口コミコムのみ | 飲食特化で「料理・接客・清潔感・雰囲気・価格」の5軸分析 |
| 改善提案生成 | ほぼ未対応 | 分析結果→具体的アクション提案をAIで自動生成 |
| トレンド分析 | 口コミコム・Birdeyeのみ | 月次推移・テーマ別推移で改善効果を可視化 |
| 日本語NLPの精度 | 海外ツールは弱い | Geminiの日本語理解力を最大活用 |
