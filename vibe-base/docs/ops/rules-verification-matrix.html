検証手順
方法: 新規プロダクトのPC表をP0から実行し、各タスクで期待する行動が発生するか記録する。

手順:
1. テスト用プロダクトのPC表を作成（全タスク × で初期化）
2. P0 #1 から順にタスクを実行
3. 各タスク完了時に「期待する行動」列の項目が実行されたか記録
4. 実行された = 発火の証拠。実行されなかった = 未発火 or ルール無視

注意:
- 全73タスクを通す必要はない。各rulesファイルにつき最低1タスクで確認すれば十分
- 常時発火の2ファイル（session-lifecycle / product-development）は全タスクで自動確認される
- structural-ops / ag-task はPCタスク外のため、別途トリガーして確認
