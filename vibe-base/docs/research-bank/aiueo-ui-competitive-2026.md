# Aiueo UI刷新 — 競合UIリサーチ結果

> 調査日: 2026-03-15
> 目的: レジ・KDS・管理画面の競合UIを調査し、Aiueoモック再設計の根拠とする

---

## 1. レジ（会計）画面

### 調査対象: Square POS / Airレジ / スマレジ / Toast POS

### 共通パターン

| 項目 | 業界標準 |
|------|---------|
| 画面構成 | **左右2〜3カラム**（商品選択 + カート） |
| 商品表示 | **グリッド（タイル）** が主流。色分け・画像付き。リスト切替可 |
| カート位置 | 左または右の固定パネル。商品名・数量・単価を行表示 |
| 合計表示 | カート下部に 小計→税→合計。合計は**太字・大フォント** |
| 支払い | 「お支払い」ボタン → 支払方法選択画面へ遷移 |
| カラー | 白背景 + ブランドカラーのアクセント。クリーン・ミニマル |
| タイルサイズ | 大・中・小の3段階カスタマイズが一般的 |

### 製品別の差分・特徴

| 製品 | 画面構成 | カート位置 | 独自要素 |
|------|---------|-----------|---------|
| **Square POS** | 3カラム（ライブラリ/キーパッド/セール） | 右 | キーパッド/グリッド切替、お気に入り固定、デュアルスクリーン |
| **Airレジ** | 2カラム（左:カート / 右:商品） | 左 | 4モード切替（タイル/リスト/検索/カスタム）、伝票情報スワイプ |
| **スマレジ** | 2カラム（左:部門+商品 / 右:カート） | 右 | かんたんモード（画像中心）、券売機モード、カラーコード直接入力 |
| **Toast POS** | 2カラム（左:チェック / 右:メニュー） | 左 | Open View（色分けカラム横並び）、**ダークモード対応**、D&D分割払い |

### カラースキーム比較

| 製品 | 背景 | ブランドカラー | ダークモード |
|------|------|--------------|-------------|
| Square | 白 #FFFFFF / ライトグレー #F5F5F5 | 青 #006AFF付近 | なし |
| Airレジ | 白 | 水色 #00AAFF〜#33BBFF | なし |
| スマレジ | 白 | 青 #0066CC〜#0088DD | なし |
| Toast | 白 or ダークグレー #1A1C23 | オレンジ #FF4C00〜#FF6600 | **あり** |

### Aiueoへの示唆

- **2カラム構成**（商品グリッド + カート）が最もシンプルで採用すべき
- 商品タイルは**カテゴリ色分け**が標準。Aiueoも部門色を活用
- 合計金額は**最も大きく・太く**。金額の視認性が最優先
- 「支払いへ進む」は画面下部の**目立つ単一ボタン**
- Toast以外はダークモードなし → 飲食POSではライトモードが主流
- タイルサイズ可変は共通機能 → Aiueoのターゲット（カフェ・居酒屋）では中サイズが適切

## 2. KDS（キッチンディスプレイ）画面

### 調査対象: Toast KDS / FreshKDS / QSR Automations CSK

### 共通パターン

| 項目 | 業界標準 |
|------|---------|
| レイアウト | **カード型（チケット型）の横並び** |
| 表示モード | 複数ビュー切替（グリッド/クラシック/タイル等） |
| カード内容 | 注文番号、注文タイプ、アイテムリスト、経過時間 |
| 時間管理 | **緑→黄→赤の信号機方式**（閾値カスタマイズ可） |
| 完了操作 | タップ/スワイプ/Bump Bar |
| ダークモード | **全製品対応**（キッチン環境では必須） |
| フォント | 大サイズ・高コントラスト（遠距離視認性） |

### 製品別の差分・特徴

| 製品 | ビューモード | 完了操作 | 独自要素 |
|------|------------|---------|---------|
| **Toast KDS** | Grid View / Legacy Dynamic | 下スワイプ / ダブルタップ / Bump Bar | フラッシュアニメ、音声通知、コースペーシング、エキスポ画面 |
| **FreshKDS** | Classic / Tiled / Split / Takeout（4種） | タップ1回 / Bump Bar | オーダーホールド、Order Tracker（顧客向け）、注文分割・結合、リアルタイム分析 |
| **QSR Automations** | カード横並び + ステーションタブ | Bump Bar(20キー) / タッチ | 動的キャパシティ管理、遅延ルーティング、KDS Builder Pro |

### 時間経過の色分け

| 段階 | 意味 | 一般的な色 |
|------|------|-----------|
| On-Time | 規定時間内 | 緑系（ヘッダー） |
| Caution | 注意が必要 | 黄色（ヘッダー） |
| Late | 即対応必要 | 赤（ヘッダー） |

### Aiueoへの示唆

- **カード型横並び**は業界標準。Aiueoもこれを踏襲
- **ダークモードは必須**（キッチンは暗い環境。全競合が対応）
- 時間経過は**ヘッダー色の信号機方式**（緑→黄→赤）が最も直感的
- フォントは**大きく・太く**。キッチンでは1m以上離れて見る前提
- 完了操作は**タップ1回**が最もシンプル（FreshKDS方式）
- モディファイア（トッピング等）は**赤テキストや太字**で強調が標準
- アイテム個別の消し込み（ストライクスルー）は実用的

## 3. 管理画面（ダッシュボード）

### 調査対象: Square Dashboard / Airレジ管理 / スマレジ管理

### 共通パターン

| 項目 | 業界標準 |
|------|---------|
| レイアウト | **左サイドバー + メインコンテンツ**（Web管理画面） |
| ダッシュボード | カード/ウィジェット型のKPIサマリー |
| 売上グラフ | 日別/月別の折れ線・棒グラフ |
| メニュー管理 | テーブル形式のCRUD + CSV一括操作 |
| カラー | 白背景 + ブランドカラーのアクセント |
| モバイル | 専用ビューアー or アプリで売上確認 |

### 製品別の差分・特徴

| 製品 | ナビゲーション | ダッシュボード | 独自要素 |
|------|--------------|--------------|---------|
| **Square** | 左サイドバー（グループ化ドロップダウン） | ウィジェット型（カスタマイズ可） | AI質問機能、7ビジネスモード |
| **Airレジ** | ホーム起点 + タブ切替 | シングルカラム（Airメイト） | Airシリーズ連携、ABC分析、完全無料 |
| **スマレジ** | 左サイドバー（階層メニュー） | KPIカード + グラフ | AI自動レポート、API公開、アプリマーケット |

### カラースキーム比較

| 製品 | 背景 | プライマリ | アクセント |
|------|------|----------|-----------|
| Square | 白/ライトグレー | 黒 | 緑 #28C101 |
| Airレジ | 白 | シアンブルー #20AEE5 | オレンジ #EB7000 |
| スマレジ | 白/ライトグレー | ブルー系 | — |

### Aiueoへの示唆

- **左サイドバー + メインコンテンツ**が管理画面の標準
- ダッシュボードは**本日の売上・取引数・客単価**をカード型で即座に把握できる設計
- 売上グラフは**時間帯別**が飲食店で最も使われる切り口
- メニュー管理はシンプルな**テーブル形式 + インライン編集**
- Aiueoのターゲット（カフェ・居酒屋の開業準備層）には**Airレジ的なシンプルさ**が合う

## 総合まとめ — Aiueo UI設計方針案

### レジ画面
- 2カラム（左: 商品グリッド / 右: カート + 合計 + 支払いボタン）
- 白背景、カテゴリ色分けタイル、合計金額を最大フォントで強調
- 参考: Airレジ（シンプルさ）+ Square（グリッドの自由度）

### KDS画面
- カード型横並び、ダークモード基本
- ヘッダーに経過時間（信号機色分け）、大フォント
- タップ1回で完了。モディファイアは色付き太字
- 参考: FreshKDS（シンプルなタップ完了）+ Toast KDS（色分けシステム）

### 管理画面
- 左サイドバー + メインコンテンツ
- ダッシュボードにKPIカード（売上・取引数・客単価）
- 時間帯別売上グラフ
- 参考: Airレジ（親しみやすさ）+ Square（ウィジェットの柔軟性）
