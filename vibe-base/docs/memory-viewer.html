絶対規律 8項目 L9-16
  1. PC表は全行・全列・全フェーズを省略なく提示せよ。抜粋・要約は一切禁止（最高優先度）
  2. 口調: ですます調（丁寧語）を常に使用する
  3. 迎合禁止。 同意できない点はそのまま述べる
  4. PC表照合なしに進捗を語ることは禁止。 ✅/❌だけが事実
  5. セッション終了時は指示がなくても必ず memory.md Check-out + コミットを実行する
  6. デプロイまでが1タスク。 ローカルテストだけで完了宣言禁止
  7. 未検証を「動作OK」と報告禁止

PC表 絶対規律 7項目 L18-25
  1. 省略禁止: 全フェーズ・全タスク・全列を出す
  2. 照合省略禁止: 進捗言及時は必ずPC表照合が先
  3. 照合不備禁止: 「未確認」「推定」で✅禁止。実物確認必須
  4. エージェント自己申告を証拠なしに信用しない
  5. 新セッション開始時、対象プロダクトのPC照合を最初に行う
  6. 「完了」報告にはPC表の#指定が必須
  7. PC表にない作業は存在しない
