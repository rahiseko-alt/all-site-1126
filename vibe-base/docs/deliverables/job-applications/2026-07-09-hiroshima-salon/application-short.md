> 構成: 4業務に同型の実物がある → Claude Code 常用 → 数字で語れる実績 → 事故を止める設計 → 非エンジニアへの伴走。

---

貴社が挙げられた4つの業務は、いずれも私が自分で作り、運用してきた領域と一致します。すべてClaude Codeで開発しています。

Google口コミの自動返信は、口コミの取得、感情とテーマの分析、トーンを選んだ150字以内の返信案の生成、投稿までを実装しました。この業務は手間の削減ではなく集客です。返信のある店舗はクリック率が2割上がり、口コミを読む人の7割は店側の返信も読んでいます。

SNS動画は、1時間のライブ配信素材から見どころを抽出してショート7本を生成し、書き出し時間を924秒から303秒に縮めました。スタッフ向けチャットとサロンボード投稿も、同型の実装があります。

いずれも全自動にはせず、AIが下書きを作り、人が承認したものだけを外に出します。誤投稿や誤返信は、4店舗ぶんの信用を一度に削るためです。

これまでエンジニアでない事業者の方に導入し、使い続けてもらうところまで伴走してきました。まず口コミ返信から着手すれば、効果が数字で見えるまでが最短だと考えています。
