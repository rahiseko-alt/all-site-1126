# LP黄金律 チェックリスト（汎用・使い回し用）

> 出典3ソース横断（VWO / Landingi / Unbounce）。LP実装前後の自己点検に使う。
> 各項目を ✅/△/❌ で判定。詳細な根拠が要る時は [統合ガイド](../templates/lp-golden-rules-guide.md) を参照。

## A. 焦点（Rule of One）
- [ ] A1 ターゲットは単一ペルソナに絞れているか
- [ ] A2 大きなアイデア（UVP）は1つに絞れているか
- [ ] A3 オファーは1つか（複数オファーで迷わせていないか）
- [ ] A4 CTAの宛先・文言は1つに統一されているか
- [ ] A5 主目標に無関係な要素を削ぎ落としているか（LP肥大化回避）

## B. 見出し
- [ ] B1 メインヘッドラインは5秒以内に価値が伝わるか
- [ ] B2 5〜9語（6語目安）・具体的・ベネフィット直結か
- [ ] B3 4-Uのうち3つ以上を満たすか（有用/独自/緊急/超具体）
- [ ] B4 「Welcome」等の曖昧語を使っていないか
- [ ] B5 サブ見出しがメインを補強・詳細化しているか

## C. 本文コピー
- [ ] C1 フィーチャーをベネフィット（顧客の成果）に変換しているか
- [ ] C2 主語が「あなた/あなたの」で顧客中心か（自分語り回避）
- [ ] C3 顧客の実際の言葉（Voice of Customer）を反映しているか
- [ ] C4 訪問者の認識段階（5段階）に合った訴求になっているか
- [ ] C5 短文・平易・箇条書き・能動態でスキマー対応しているか
- [ ] C6 声に出して不自然でない会話的トーンか
- [ ] C7 業界用語・バズワードを避けているか

## D. 社会的証明
- [ ] D1 顧客証言/推薦/レビュー/ロゴ/バッジのいずれかがあるか
- [ ] D2 証明に具体的な数値が含まれているか
- [ ] D3 ターゲットが同一化できる人物の声か
- [ ] D4 CTA/コンバージョンポイントの近くに配置されているか
- [ ] D5 主張に証拠が伴っているか（証拠なき主張の排除）

## E. CTA
- [ ] E1 結果志向の動詞か（「Submit」等の汎用語回避）
- [ ] E2 押すと何が起こるか具体的に明示されているか
- [ ] E3 見出し・オファーとメッセージが一致しているか（メッセージマッチ）
- [ ] E4 フォーム項目・選択肢が最小化されているか
- [ ] E5 長ページでCTAが反復配置されているか
- [ ] E6 ファーストビュー内にCTAが視認できるか

## F. 構成・情報階層
- [ ] F1 痛点→ベネフィット→差別化→反論対処→社会的証明→CTA の流れか
- [ ] F2 広告/流入元とのメッセージマッチが取れているか
- [ ] F3 ベネフィット→フィーチャーの順（成果を先に）か
- [ ] F4 反論・不安への対処（FAQ等）があるか

## G. 信頼・リスク低減
- [ ] G1 リスク反転（無料/保証/解約明確化）があるか
- [ ] G2 緊急性/FOMOを乱用していないか（控えめか）
- [ ] G3 ブランドの視覚的一貫性（色/フォント/トーン）があるか
- [ ] G4 プライバシー/法令配慮が示されているか

## H. 技術・計測
- [ ] H1 モバイル最適化・親指操作可能なレイアウトか
- [ ] H2 表示速度が軽量・高速か
- [ ] H3 A/Bテスト・改善のループが回せる状態か

---

## 判定の勘所（3ソースが最重視する順）

1. **社会的証明（Dブロック）** — コピーはLPコンバージョンの約70%を占め、中でも社会的証明は3ソース共通の必須。証言＋具体数値が最重要。
2. **Rule of One（Aブロック）** — 焦点が散ると全体が弱る。
3. **ベネフィット変換（C1）＋見出し（B）** — 5秒で価値が伝わらなければ読まれない（訪問者はページの30%未満しか読まない）。
