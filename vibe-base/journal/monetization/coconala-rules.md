# 目的とスコープ

## 目的（1文）
AIチャットボット制作カテゴリで7出品中のマスターが、ココナラ規約違反・文字数オーバー・最低価格未満・カテゴリ規定違反を起こさず安全に出品文を改稿できる状態を作る。

## スコープ宣言
- 対象: AIチャットボット制作カテゴリ（大分類: AI導入・生成AI活用相談）の出品ルール
- 含む: 文字数制限・最低価格・禁止表現・画像/動画仕様・検索順位ロジック・レビュー集計単位・販売実績集計範囲・カテゴリ階層・セラーランク・PRO認定制度・セラーサクセス・広告（プロモーション）枠
- 含まない: 他カテゴリ専用ルール、購入者向けルール、決済の詳細、税務処理

## 調査制約
- 検索回数上限: 12回（中規模）→ 本調査の実績: 12回（上限到達）
- WebFetchツールは権限拒否されたため、WebSearchのみで実施
- 公式ヘルプ（coconala-support.zendesk.com）・公式ニュース（coconala.com/news）を優先、第三者ブログは補助参照
