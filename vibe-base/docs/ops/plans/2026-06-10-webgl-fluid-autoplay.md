# WebGL Fluid Simulation 自動巡回（Autoplay/Idle）機能追加計画

コウヘイさんのご依頼に基づき、マウスやタッチ操作がない時に機械的でチープなループではなく、自然で有機的な美しいうねりを描いて永続動作し続ける「自動巡回モード（Auto-pilot / Idle mode）」を `agent-ag/webgl-fluid-demo/script.js` に実装します。

## User Review Required

- **自然なゆらぎ（多重サイン波合成）の採用:**
  - 単純な円運動（リサージュ曲線）や単調な往復運動は「機械的でチープなループ」に見えてしまうため、周波数の異なる 3 つのサイン・コサイン波を重ね合わせた多重合成アルゴリズムを採用し、カオス的でありながら極めて滑らかな「二度と同じ軌跡を通らない有機的な動き」を実現します。
- **アイドル時のシームレスなフェードアウト/フェードイン:**
  - ユーザーが操作している間は通常のマウス操作のみが有効。
  - 操作が 3 秒間途絶えると自動巡回モードへ移行し、見えない 5 本のオートポインタが動き始めます。
  - 再度ユーザーが操作を検知すると、即座に自動巡回は停止し、通常インタラクションへとシームレスに戻ります。

2. 以下の挙動を手動検証します：
   - 画面を操作せずに 3 秒間放置すると、自動的に画面上の複数箇所から美しく色彩豊かな流体がうねるように噴き出し、永続的に動き始めること。
   - 自動巡回中の動きが単調なループ（同じ円を繰り返す等）ではなく、生物の動きや水中のうねりのように自然であること。
   - マウスを動かすかタッチ操作を行うと、自動巡回がピタッと止まり、通常通り自分の手元の動きに追随すること。
