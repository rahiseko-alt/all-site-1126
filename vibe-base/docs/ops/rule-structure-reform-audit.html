2. 改革の背景と課題定義

システム概要

vibe-baseは複数のAIエージェント（Claude Opus/Sonnet等）が協調して10+プロダクトを開発するモノレポ基盤。各エージェントはセッション単位で起動し、MISSION_LOG.mdで引き継ぎながら作業を進める。

課題: 参照断絶

32本のSOPをCLAUDE.md §3に列挙し、エージェントに「作業開始前に該当SOPを自分で判断して読め」と指示していた。しかし:

  • 判断誤り: 自分の作業に該当するSOPを正しく選べない（32本から選ぶ認知負荷）
  • 読み飛ばし: 面倒で開かない。特にコンテキスト枯渇時に顕著
  • 結果: ルール違反→手戻り→マスターからの是正→同じ指摘の繰り返し

Before: Pull型

CLAUDE.md §3（32行のSOP索引表）

  • エージェントが32行の表を読む
  • 自分の作業に該当するSOPを判断
  • 該当SOPファイルを手動で開く
  • 全文を読んで要点を理解

4ステップの判断が必要。各ステップで失敗の可能性がある。

After: Push型

.claude/rules/（13ファイル、paths指定）

  • エージェントがファイルにアクセス
  • pathsパターンに一致→自動注入
  • 要点がsystem-reminderとして表示
  • 詳細が必要なら参照リンクから全文へ

判断ステップ0。読み忘れが構造的に発生しない。

#!/bin/bash # PostToolUse:Write|Edit -- 持続性ガード（#1 SOP未カバー / #2 @import漏れ / #3 §3肥大化） INPUT=$(cat) FILE=$(echo "$INPUT" | node -e "let d='';process.stdin.on('data',c=>d+=c);process.stdin.on('end',()=>{try{console.log(JSON.parse(d).tool_input.file_path)}catch(e){console.log('')}})") if [ -z "$FILE" ]; then exit 0; fi FILE=$(echo "$FILE" | sed 's|\\|/|g') BASE_DIR="/c/Users/user/Desktop/ClaudeCode/vibe-base" RELPATH=$(echo "$FILE" | sed 's|.*/vibe-base/||') # #1: SOP未カバー検知 if echo "$RELPATH" | grep -qE '^docs/ops/[^/]+\.md$'; then SOPNAME=$(basename "$RELPATH") case "$SOPNAME" in project-promotion.md|shared-asset-ops.md|beginner-dns-nav.md|revision-history.md) exit 0 ;; esac COVERED=0 if grep -rl "$SOPNAME" "$BASE_DIR/.claude/rules/" >/dev/null 2>&1; then COVERED=1; fi if [ "$COVERED" -eq 0 ]; then echo "{\"decision\":\"block\",\"reason\":\"SOP未カバー: $SOPNAME が .claude/rules/ から参照されていません\"}" exit 0 fi fi # #2: @import漏れ検知 if echo "$RELPATH" | grep -qE '^products/[^/]+/CLAUDE\.md$'; then UNIX_FILE=$(echo "$FILE" | sed 's|^C:|/c|') if [ -f "$UNIX_FILE" ]; then if ! grep -q '@docs/ops/agent-rules.md' "$UNIX_FILE" 2>/dev/null; then echo "{\"decision\":\"block\",\"reason\":\"@import漏れ: $RELPATH に @docs/ops/agent-rules.md がありません\"}" exit 0 fi fi fi # #3: §3肥大化防止 if echo "$RELPATH" | grep -qE '^CLAUDE\.md$'; then UNIX_FILE="$BASE_DIR/CLAUDE.md" if [ -f "$UNIX_FILE" ]; then LINES=$(wc -l < "$UNIX_FILE") if [ "$LINES" -gt 60 ]; then echo "{\"decision\":\"block\",\"reason\":\"CLAUDE.md が ${LINES}行（上限60行超過）\"}" exit 0 fi fi fi exit 0
