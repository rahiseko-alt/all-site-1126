# Responsive Checklist

デバイス幅や親コンテナの幅に依存しない、堅牢で流動的なレスポンシブデザインを担保するためのチェックリストです。

## 1. 静的コードレビュー項目

### メディアクエリ (Media Queries)
- [ ] ブレークポイントに固定のピクセル値（例: `max-width: 768px`）を多用せず、必要最小限に留められているか。
- [ ] ブレークポイントには `px` ではなく、ユーザーのフォントサイズ設定に連動する `em` または `rem` が使用されているか（例: `48rem` = 768px）。

```css
/* 推奨されるメディアクエリの記述 */
@media (max-width: 48rem) {
  .sidebar { display: none; }
}
```

### コンテナクエリ (Container Queries)
- [ ] コンポーネント単体のレイアウト変化が、ビューポート（`@media`）ではなく親コンテナの幅（`@container`）に基づいて設計されているか。これにより、サイドバー内でもメインエリア内でもコンポーネントが自律的に適応する。

```css
/* コンテナクエリの正しい適用例 */
.widget-wrapper {
  container-type: inline-size;
}

.widget {
  display: flex;
  flex-direction: column;
}

/* 親要素の幅が400pxを超えたら横並びにする */
@container (min-width: 400px) {
  .widget {
    flex-direction: row;
  }
}
```

### 流体タイポグラフィとスペーシング
- [ ] フォントサイズや余白に `clamp()` や `vw/vh` を活用し、画面サイズに応じて滑らかに伸縮する設計になっているか（固定の `px` 指定によるレイアウト破綻がないか）。

### CSS Grid と Flexbox の弾力性
- [ ] Gridレイアウトで、`auto-fit` や `auto-fill`、`minmax()` を活用し、メディアクエリなしでも列数が自動調整されるようになっているか。

```css
/* メディアクエリ不要のレスポンシブGrid */
.auto-grid {
  display: grid;
  gap: 1.5rem;
  grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
}
```

- [ ] Flexboxにおいて、アイテムがコンテナから溢れる場合への備え（`flex-wrap: wrap` や `min-width: 0` など）ができているか。

## 2. 動作確認手順 (人間向け指示)

AIはブラウザを直接操作してレスポンシブ表示を確認できないため、司令塔（人間）に以下の確認を依頼します。

1. **DevToolsを用いた縮小・拡大テスト**: ブラウザの開発者ツールを開き、幅を `320px`（モバイル最小）から `1920px`（フルHD）まで滑らかに伸縮させ、横スクロールバーが出ないこと、テキストが重ならないことを確認してください。
2. **ズームテスト**: ブラウザのズーム機能を200%に拡大し、UIが崩れたりアクセス不能なボタンが発生したりしないか確認してください。
