# Add to Cart (カスタマイズ版)

## 概要
ユーザーインタラクションに応じて、Tシャツのアイコンが落ちてカートに収まり、カートが移動してチェックマークに変わる「マイクロインタラクション」を実装したデモ。
さらに、グラスモーフィズム調のコントロールパネルから、各要素のカラーとメッセージテキストをリアルタイムで変更できる機能を備えています。

## 関連技術スタックと使用トリック

### 1. SVG モーフィング (MorphSVGPlugin)
- **技術**: `GSAP` ＋ `MorphSVGPlugin` (Webflow 買収以降は全プラグイン無料・auth token 不要)
- **用途**: ボタンの上部が服の重みでへこむ（ぷにっとした）質感を表現。パスデータ (`M0 12C6...`) を時間経過とともに別のパスに滑らかに変形させることで、有機的なアニメーションを実現。

### 2. CSS カスタムプロパティ (CSS変数) とリアルタイムDOM更新
- **技術**: `var(--変数名)` ＋ `element.style.setProperty()`
- **用途**: JavaScriptから直接各要素の色を変えるのではなく、親要素に設定されたCSS変数を書き換えることで、それに依存する全ての子要素の色を一括で変更。

### 3. Clip-Path による「隠蔽」と「色反転トリック」
- **技術**: `clip-path: polygon(...)` ＋ 重ね合わせられた2枚の同一SVG
- **用途**: カートに入る際に服の色が「背景色と同化する」トリック。白と黒の2枚のシャツを用意し、カートの縁のY座標を基準に `clip-path` で上半分・下半分をマスクすることで、境界線を越えた瞬間に色が反転（消えたように見える）するイリュージョンを実現。

### 4. Glassmorphism (グラスモーフィズム)
- **技術**: `backdrop-filter: blur(10px)` ＋ `background: rgba(255, 255, 255, 0.1)`
- **用途**: コントロールパネルを背景の透過度を持たせつつ、すりガラスのようにぼかすことで、モダンでプレミアムなUIを表現。

### 5. 疑似要素 (`::before`) の独立スケールアニメーション
- **技術**: `transform: scaleX(...)` on `::before`
- **用途**: ボタンをクリックした際の「へこみ」アニメーション。ボタン本体（中のテキストやSVG）まで一緒に縮まないように、背景だけを描画する疑似要素を配置し、それのみをスケール変更させている。
