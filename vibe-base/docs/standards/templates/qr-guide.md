# QRコード発行・設置ガイド テンプレート

## 5W2H

| 項目 | 内容 |
|------|------|
| **What** | QRコードで端末にロールを割り当てるプロダクト向けの、クライアント配布用ガイド |
| **Why** | QR発行→印刷→設置の手順を1枚にまとめ、クライアントがセルフで端末セットアップできるようにする |
| **Who** | エージェントがテンプレートをコピー → プロダクト固有の内容に書き換え → クライアントに送付 |
| **When** | 納品時。ログイン情報（client-credentials）と一緒に渡す |
| **Where** | テキストチャネル（md版）またはブラウザで編集→印刷（html版を別途作成する場合） |
| **How** | `{{...}}` 部分をプロダクト固有の内容に置き換える |
| **How much** | コピペ+置換で3分。ロール定義のカスタマイズ込みで10分 |

  ─────────────────────────────────────────
  {{ロール1}}    {{用途の説明}}         {{設置場所}}

  {{ロール3}}    {{用途の説明}}         {{設置場所}}


■ 発行手順

【手順1】管理画面にログイン
  {{管理画面URL}}
  メール: {{Admin Email}}
  パスワード: （お送り済みのもの）

【手順2】QRコード発行画面を開く
  {{QR発行画面への導線。例: 左メニューの「Roles & QR」をタップ}}

【手順3】役割を選んで発行
  1. {{役割選択の操作説明}}
  2. 「ラベル」に名前を入力（例: {{ラベル例}}）
  3. 「発行」ボタンをタップ

  ※ QRコードを長押し→画像保存も可能
  ※ テーブル設置用はラミネート加工すると長持ちします

【手順5】端末でスキャンして設置
  印刷したQRコードを各端末のカメラでスキャンします。
  スキャン後、ブラウザが開いてその役割の画面が表示されます。
  {{ロールごとの補足。例: Kitchen/Cashierは端末に1回スキャンすればOK}}

## 変数一覧

| 変数 | 説明 | 例（Aiueo） |
|------|------|------------|
| `{{プロダクト名}}` | サービス名 | Aiueo モバイルオーダーシステム |
| `{{管理画面URL}}` | 管理画面のURL | https://xxx.vercel.app/?view=admin |
| `{{ロールN}}` | 端末ロール名 | Ordering / Kitchen / Cashier / Daddy |
| `{{QR発行画面への導線}}` | QR発行画面の開き方 | 左メニューの「Roles & QR」をタップ |
| `{{ラベル例}}` | ラベルの具体例 | テーブル1、厨房iPad |
| `{{有効期限}}` | QRトークンの有効期限 | 発行から1年間 |

## カスタマイズ指針

- ロール一覧はプロダクト固有。QRでロール認証する仕組みを持つプロダクトのみ使用
- FAQ は実際の問い合わせに応じて追加・削除する
- 印刷版（HTML）が必要な場合は client-credentials.html のデザインを踏襲して作成する
