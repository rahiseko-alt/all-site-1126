# 独自ドメイン（サブドメイン）公開：初心者ナビ 📝

Cloudflare で A レコードを追加し、任意のサブドメイン（例: `blog.kouheikosehira.com`）で Vercel サイトを見れるようにする手順です。

## ステップ 1: Cloudflare にログイン
1. [Cloudflare ダッシュボード](https://dash.cloudflare.com/) にアクセスしてログインします。
2. 対象のドメイン `kouheikosehira.com` をクリックします。

## ステップ 2: DNS 設定を開く
1. 左側のメニューにある **[DNS]** -> **[レコード]** をクリックします。

## ステップ 3: レコードを追加する
1. **[レコードを追加]** ボタンをクリックします。

## ステップ 4: 以下の値を入力する
項目の通りに、以下の値をそのままコピー＆ペーストしてください。

| 項目 | 入力する値 | 備考 |
| :--- | :--- | :--- |
| **種類 (Type)** | `A` | 一番上の選択肢です |
| **名称 (Name)** | `blog`（任意のサブドメイン名） | サブドメインの頭文字です |
| **IPv4アドレス** | `76.76.21.21` | Vercel の共通サーバーIPです |
| **プロキシ状態** | `DNS のみ (DNS only)` | 雲のアイコンをクリックして灰色にします |

2. 入力が終わったら **[保存]** ボタンをクリックします。

---

## ステップ 5: 完了の確認
1. 保存後、5分〜10分ほど待ちます。
2. 以下の URL にアクセスしてみてください。
   👉 `https://<サブドメイン名>.kouheikosehira.com`（例: `https://blog.kouheikosehira.com`）

> [!TIP]
> **「プロキシ状態」のコツ**
> 雲のアイコンが **オレンジ（プロキシ）** ではなく **灰色（DNSのみ）** になっていることを確認してください。Vercel が自動で SSL 証明書を発行する際に、灰色の方がスムーズに完了します。

> [!IMPORTANT]
> **SSL エラーが出る場合**
> 保存直後は「保護されていない通信」と表示されることがありますが、Vercel 側が証明書を自動発行している最中です。1時間ほど経っても直らない場合は、Antigravity（私）を呼んでください！
