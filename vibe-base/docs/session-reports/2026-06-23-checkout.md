## 🔴 最重要

1. **権限モデルを変更した。** `.claude/settings.json` の deny をマスターの安全境界（①デプロイ ②シークレット ③アカウント ④不可逆 のみ）に絞り、**git push を AI に許可**（`git push:*` deny 撤去・`--force`/`rm -rf`/`reset --hard`/`.env`/`secrets`/`gh auth`/`git config user` は保護）。デプロイ（`vercel --prod`/`npm publish`）は ask。正本 → ADR-0003。
