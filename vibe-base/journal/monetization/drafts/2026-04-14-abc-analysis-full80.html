§6. 発見事項と戦略的示唆

発見1: 寡占構造は確実に存在

  • A群14件（全体の17.5%）が評価総数の78.5%を占める
  • 上位3件（ohr / n00518 / tanaka_s_001）だけで 34.1%
  • B群14件は16.1%、C群51件は5.4% → 65件が合計21.5%でひしめき合っている
  • マスターの仮説「上位寡占に食い込まないと芽も出ない」は データで裏付けられた

発見2: A群は「低単価で大量受注」がメインパターン

  • A群14件の 中央値 ¥3,500・8件が ¥3,000-¥4,999 帯
  • ¥3,000帯 A群: n00518, 室内森林浴, 占いプログラマDeguchi, カスミ, crane_design, ayan, ココ生活 の7件
  • ¥4,000〜¥9,000帯 A群: ohr(¥6k), 鶴屋(¥9k), ochuchun(¥4k) の3件
  • ¥10,000以上のA群は 4件のみ（エイトさん / いき育児中 / キタノネコ / tanaka_s_001）

発見3: 高単価A群は「特殊ポジション」

  • tanaka_s_001 ¥45,000 = 自動購入ツール（競合ほぼ無し・法的グレー領域あり）
  • いき育児中 ¥29,000 = 「何でも承る」ブランド化されたプロ
  • エイトさん ¥10,000 = Pythonスクレイピング特化（カテゴリ内唯一のPython強豪）
  • キタノネコ ¥15,000 = VBAエキスパート認定（資格訴求）
  • → いずれも 簡単に真似できない要素 を持つ

戦略的示唆（空白地帯分析）

A群の価格帯別にすでに埋まっている軸:
  • ¥3,000帯: 汎用Excel/GAS/Python自動化、スプレッドシート作業、LINE予約、Octoparse代行 → 飽和
  • ¥4,000-¥9,000帯: わずか3件。空白地帯の可能性あり
  • ¥10,000-¥29,000帯: 特殊スキル訴求でA群入り（Pythonエキスパート / VBA資格 / ブランド）
  • ¥45,000帯: 自動購入ツール（グレー領域）独占
新規参入の現実:
  • ¥3,000 で A群と真っ向勝負は不可能（レビュー169-992件の壁）
  • ¥4,000-¥9,000 の空白地帯で差別化軸を持つのが現実的
  • 差別化軸候補: 業種特化（医療事務 / 美容室 / 保育園 / 建設業）/ 納期保証 / 返金保証 / 画面共有サポート / ¥4,000代で中身¥9,000相当 の逆張り
  • ABC分析は「何が埋まっているか」を教えてくれるが「何が埋まっていないか」は創造力の問題
