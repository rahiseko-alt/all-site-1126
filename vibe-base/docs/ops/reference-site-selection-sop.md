# 参考サイト選定SOP v1.1

## §0. 目的
プロダクトのデザイン改善・新規デザイン時に、的確な参考サイトを選定するための手順を定める。
コンセプト起点の選定を標準化する。

## §1. 適用タイミング
- P1 #6a（UI設計書作成）の競合調査・参考サイト選定時
- デザインリニューアル・UI刷新時

## §2. 手順

### Step 1: コンセプト確認
対象プロダクトの以下を確認する。自治憲法（CLAUDE.md）が正本。

| 確認項目 | 確認先 |
|----------|--------|
| サービス名の意味・由来 | 自治憲法 §0 |
| 一言コンセプト | 自治憲法 §0 |
| ターゲット人物像 | 自治憲法 §0 / P0結果 |
| 収益モデル | 自治憲法 §4 等 |

**出力:** コンセプト要約（3行以内）

### Step 2: 制作物の種類を特定し、今回のスコープを決める

**やること:**
1. このプロダクトに必要な制作物の種類をすべて列挙する
2. **今回作るものを決める**（全部を同時に作らない。スコープを絞る）
3. 決めたものに対してStep 3以降を実行する

**分類表（参照）:**

| 種類 | 役割 |
|------|------|
| LP | 説得して行動させるページ（Last Punch） |
| SaaSアプリUI | ログイン後（または利用開始後）の操作画面 |
| 組織サイト / ポートフォリオ | 情報提供・信頼構築 |
| EC | 商品販売 |
| メディア / ブログ | コンテンツ発信 |
| ダッシュボード | 管理・分析画面 |

**⚠️ スコープ分離:** 同一プロダクトでLP・APP UI等の複数種類が必要な場合、**種類ごとに独立してStep 3-6を回せ。** LP参考サイトをAPP UIに流用するな。逆も禁止。感情軸・ターゲットの目線・分解対象が異なる。

**出力:**
```
必要な制作物:
1. ○○
2. ○○

今回作るもの: ○○（他の種類は別途実施。混同しない）
```

### Step 3: 伝えるべき感情の定義
Step 1のコンセプトから、画面越しにユーザーに伝えるべき感情を言語化する。

**やること:**
- サービス名・メタファーから連想される感情を3〜5語で列挙する
- ターゲットが「このサービスは自分向けだ」と感じるために必要な空気を言語化する
- 逆に、ターゲットが離脱する空気も言語化する（NOT DO）

**出力:**

```
伝えるべき感情: ○○ / ○○ / ○○
避けるべき印象: ○○ / ○○ / ○○
```

**⛩ ゲート: Step 3の出力をマスターに提示し、GO判定を得るまでStep 4に進むことを禁止する。**

### Step 4: 感情軸 × 種類別で参考候補を検索する
Step 3の感情をキーワードに、Step 2で決めた種類ごとに参考サイトを探す。

**ルール:**
- 感情が一致するサイトを、ジャンル横断で探す
- 検索クエリ例: 「やさしい 安心 日本語 LP」「初心者向け SaaS デザイン」「育てる 成長 ウェブサービス」
- 種類ごとに候補を5〜8サイト出す（次Stepで絞る）

**出力:** 種類別の候補リスト（URL + 選定理由1行）

### Step 5: ターゲットの目でフィルターする
Step 4の候補を、ターゲットユーザーの視点で絞り込む。

**チェック項目:**
- [ ] ターゲットが日常的に見ているサイトの美的水準と乖離していないか
- [ ] ターゲットの言語（日本語/英語）と一致しているか。日本人ターゲットなら日本語サイトを最低1つ含む
- [ ] ターゲットが「怖い」「自分向けではない」と感じる要素がないか（例: 黒背景はシニア・非エンジニアに不向き）
- [ ] 実際にライブサイトを目視確認したか（トレーニングデータの記憶で判断していないか）

**出力:** 種類ごとに最終選定 3サイト（URL + 選定理由 + 盗むべき印象）

### Step 6: 印象の逆算分解
選定した参考サイトを開き、「印象」がどのデザイン要素から生まれているかを逆算する。

**CSS計測が必要な場合** → `/web-design` フロー Step3-4（参考実物を自分の目で計測・分解）に従う。Playwright 等で計測可（旧 `/reference-site-measure` skill は廃止）。

**分解項目:**

| 項目 | 何を見るか |
|------|-----------|
| 第一印象（3秒） | 開いた瞬間の空気は何か。その空気はどこから来ているか |
| 色 | 背景色・メインカラー・アクセントカラーの数と比率 |
| 余白 | セクション間・要素間の空き。密度感 |
| タイポグラフィ | 書体の温度感（冷たい/温かい）。サイズ差のコントラスト |
| コピー | 文体のトーン。敬語/タメ口。専門用語の有無 |
| 画像/イラスト | 写真かイラストか。人の有無。色温度 |
| 動き | アニメーションの量と速度。静的か動的か |

**出力:** 参考サイトごとの分解表

## §3. 禁止事項
1. **部品単位のコピーを禁止する。** 「このボタンの角丸をもらう」ではなく「この安心感をもらう」。部品は印象の逆算結果として出てくるもの
2. **ライブサイト未確認での選定を禁止する。** 必ずブラウザで開いて目視した上で選定する
