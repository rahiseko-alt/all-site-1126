## [2026-06-12] 電撃シミュレーターの機能強化調査（Antigravity）

### 1. 線の太さ調整の検証
WebGLでは多くのブラウザ環境で `LineBasicMaterial` の `linewidth: 1` 制限があるため、代わりに `currentPoint` と `nextPoint` にノイズを加えた複数の線を束ねて多重描画するアプローチを検討・採用。太さが `w` (1〜5) に応じて、オフセットを加えながら `w` 回描画することで電撃の束を表現した。

### 2. レインボー（マルチカラー）表現の追加
HSL空間において、`Date.now()` と接続の頂点インデックスに応じて色相（Hue）を動的に回転させるロジックを `animate()` に導入。`hslToRgb` 変換関数を用いて頂点カラー（RGB）をフレームごとに更新するようにした。
