# ドン詰まり台帳（Dead-End Registry）

> **目的:** 外部サービスの既知の制約を蓄積し、P0 #10（フィルタ評価）で照合させる。同じ轍を踏まない。
>
> **参照タイミング:** P0 #10 フィルタ評価時（必須）
>
> **追記タイミング:** ドン詰まりに当たった時（Check-out必須項目）
>
> **ルール:**
> - 「選ぶな」ではない。「選んだなら、このタイミングでこの対処が要る」を記録する台帳
> - ヒットした制約は、memory.md P1に対処タスクとして追加すること（rationaleに埋めない）
> - 新規エントリ追記時はバージョンを上げる
