## 横断の訴求軸

### 1. human-in-the-loop を全ツールで一貫させている

3ツールすべてで「AIが下書きを作り、人が承認した分だけ外に出る」構造を採っている。

- instagram-auto-ops: Sheets の承認列
- video-shorts: 承認UIで採用・破棄を選別
- review-analysis: 返信文を生成し、人が確認してから投稿

美容室では誤投稿・誤返信が店舗の信用に直結する。止める場所を設計に組み込んでいる点が、求人の「仕組みからサポート」に対応する。

### 2. AIに開発させても事故らせない基盤

破壊的コマンドやシークレット混入を hook で機械的に停止し、実装役と検証役を分離（Worker / Evaluator）。受け入れ基準は意図と機械検証の両方で書く。エージェント定義12体、hook 約24本。

導入先が今後 Claude Code を社内で使い続ける前提なら、この運用ルールの整備そのものが納品物になる。

### 3. GUI自動化の限界を知っている

サロンボードのように公式APIがない対象は、ブラウザ自動化が唯一の経路になる。実装経験と、それが画面変更で破綻する脆さの両方を持っているため、規約確認・保守設計・代替案（手動投稿＋下書き生成のみ自動化）を最初に提示できる。
