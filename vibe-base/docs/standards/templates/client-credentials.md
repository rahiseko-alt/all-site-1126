# クライアント納品メッセージ テンプレート

> **用途:** 暗号化チャネル（Signal等）でクライアントにログイン情報を送付する際のコピペ用
> **変数:** `{{...}}` を実際の値に置換して使用

### これは何か

お客さんに「あなたのログインIDとパスワードはこれです」と伝えるメッセージの雛形。鍵を渡すときに「玄関の鍵です。使い方は…」と一緒に説明書を添えるのと同じ。テキストチャネル（ココナラトーク等）にコピペして送る。

### 5W2H

| 項目 | 内容 |
|------|------|
| **What** | クライアントにログイン情報を送付するためのコピペ用メッセージテンプレート |
| **Why** | 毎回ゼロから書くと情報の抜け漏れが出る。雛形があれば「変数を埋めるだけ」で送れる |
| **Who** | エージェントが `{{...}}` を実際の値に置き換え → クライアントに送付 |
| **When** | 納品完了時。セットアップ作業が終わった直後 |
| **Where** | ココナラトーク / LINE / メール等のテキストチャネル |
| **How** | テンプレをコピー → `{{店舗名}}` `{{URL}}` `{{パスワード}}` 等を実際の値に置換 → 送信 |
| **How much** | コピペ+置換で1分 |

## 値の取得方法

| 変数 | 取得元 |
|------|--------|
| `{{店舗名}}` | クライアント名 |
| `{{フロントエンドURL}}` | `deploy-client-frontend.sh` の出力 |
| `{{Admin Email}}` | `provision-client.sh` の出力 |
| `{{Admin Password}}` | サーバー `/pb-clients/registry.json` |
