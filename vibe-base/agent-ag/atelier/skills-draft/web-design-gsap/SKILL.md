# Web Design GSAP

## 概要
GSAP (GreenSock Animation Platform) を用いた、ブラウザ間で安定動作する高性能なアニメーション実装スキルです。2025年4月より全プラグインが無料・商用利用可能になっています。

## ⚠️ ライセンス制約事項（極めて重要）
GSAPは一般的な商用Webサイトやアプリでは完全に無料で使用できますが、**「Webflowのビジュアルアニメーション構築機能と競合するツール」の開発に使用することは明示的に禁止**されています。この制約に抵触するプロダクト開発の依頼を受けた場合は、GSAPの使用を拒否してください。

## 使用手順

ユーザーの要望に応じて、以下の判断フローに基づき、**必要な1つの参照ファイルのみ**を `view_file` ツールで読み込んでください。

### 判断フローチャート

1. **基本的なアニメーション、タイムライン、連続（stagger）アニメーション**が必要な場合
   👉 `references/gsap-core-patterns.md` を読み込む
   *(GSAP Core, Timeline, Stagger, CDN設定)*

2. **スクロールに連動するアニメーション、要素のピン留め**が必要な場合
   👉 `references/gsap-scrolltrigger.md` を読み込む
   *(ScrollTrigger)*

3. **テキストの文字単位・単語単位でのアニメーション**が必要な場合
   👉 `references/gsap-text-effects.md` を読み込む
   *(SplitText)*

4. **レイアウトの劇的な変更、DOM移動時のアニメーション**が必要な場合
   👉 `references/gsap-advanced.md` を読み込む
   *(Flip)*

## トークン節約ルール（厳守）
1. `references/` ディレクトリ内のファイルは、「必要な1ファイルだけ」読み込みます。全読み込みは禁止です。
2. 1つのタスクで参照するファイルは最大2ファイルまでに制限してください。
3. 同一セッションで既に読み込んだファイルは再読み込みしないでください。
4. 提供されているコードはコピペ可能な完全なスニペットです。必要な部分だけをクリップして使用してください。
