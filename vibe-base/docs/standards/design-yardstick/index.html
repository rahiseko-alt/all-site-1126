よくあるご質問

不安なところ、
先にお答えします。

ITに詳しくないのですが、使えますか？
はい。入力はフォームに沿って打つだけです。使い方のレクチャー込みなので、担当の方が迷わず使えるところまでお手伝いします。
専用ソフトの月額費用はかかりますか？
かかりません。お使いの Google スプレッドシート／Excel の上で動く「買い切り」です。毎月の利用料は不要で、御社の資産として手元に残ります。
代行サービスとは何が違うのですか？
代行（農園型・サテライトオフィス型）は、働く場所や日常サポートを社外が担います。当社は雇用も記録も御社の手元に残す仕組みづくりなので、ノウハウが社内に蓄積していきます。
制度のことがよく分かっていません。
無料相談で、制度の確認から一緒に進めます。厚生労働省など一次情報の出典に基づいて、御社が「やるべきこと」を整理してご案内します。
名古屋以外でも対応できますか？
オンラインで全国対応します。名古屋・愛知近郊であれば、直接お伺いしての打ち合わせも可能です。
導入実績はありますか？
正直にお伝えすると、この記録支援サービスは新しく始めたばかりで、実績の「数」はまだありません。その分、初期のお客様には特に丁寧に、御社に合わせて作り込みます。
本当に1万円からですか？
会社の規模や記録する項目数によって変わります。無料相談のうえで、金額をはっきり提示してから進めます。見えない追加費用はありません。
