# 性能ベースライン計測表テンプレート

### これは何か

「今どれくらいの速さで動いているか」を記録する表。ページ表示○秒、API応答○秒、エラー率○%。P4で「遅くなってないか」を確認するときの比較元になる。基準がないと劣化に気づけない。

### 5W2H

| 項目 | 内容 |
|------|------|
| **What** | 主要操作の応答時間・エラー率・リソースサイズを計測し記録するテンプレート |
| **Why** | P4で劣化検知するにはP1時点の基準値が必要。「遅くなった気がする」を数値で判定する |
| **Who** | エージェントが計測・記入 |
| **When** | 性能ベースライン計測時 |
| **Where** | vest1: docs/standards/templates/performance-baseline.md → 各プロダクトの docs/ にコピー |
| **How** | DevTools/Lighthouse/curlで計測 → 表に記入 → P4で再計測して比較 |
| **How much** | 計測30分 |
