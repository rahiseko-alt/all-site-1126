# Web Design Quality Gate

## 概要
実装されたWebデザインの品質を担保するための最終チェックポイント（品質ゲート）を提供するスキルです。アクセシビリティ、パフォーマンス、レスポンシブ、CSS設計品質の4つの観点から検証を行います。

## 使用手順

ユーザーからレビューや品質チェックの依頼があった場合、以下のフローに従って該当のチェックリスト（参照ファイル）を読み込み、コードの検証や手動・自動テストの指示を行ってください。

### 判断フローチャート

1. **アクセシビリティ（WCAG準拠、Aria、コントラスト等）の確認**が必要な場合
   👉 `references/accessibility-checklist.md` を読み込む

2. **表示速度、Core Web Vitals、レンダリングの最適化**が求められている場合
   👉 `references/performance-checklist.md` を読み込む

3. **多様な画面サイズ（ブレークポイント、Container Queries）での崩れ確認**が必要な場合
   👉 `references/responsive-checklist.md` を読み込む

4. **CSS の設計品質（デザイントークン一貫性、未使用 CSS/JS、複雑度・詳細度）の客観計測**が必要な場合
   👉 `references/css-quality-checklist.md` を読み込む（Project Wallace / Chrome DevTools Coverage 手順・全プロダクト共通・context 消費ゼロ）

## トークン節約ルール（厳守）
1. `references/` ディレクトリ内のファイルは、「必要な1ファイルだけ」読み込みます。全読み込みは禁止です。
2. 1つのタスクで参照するファイルは最大2ファイルまでに制限してください。
3. 同一セッションで既に読み込んだファイルは再読み込みしないでください。
4. このスキルはコードを「生成」するよりも「検証・修正」することに重きを置いています。提供されるチェックリストに基づいて既存コードを評価してください。
