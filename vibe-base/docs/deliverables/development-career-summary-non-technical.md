# 開発経歴書（非技術者向け）

## 希望ポジション

AI活用型フルスタック / 業務自動化プロトタイプエンジニア

社内DX、AI導入支援、業務自動化、Webサービス試作、営業資料・LP・デモ制作を横断して担当できます。特に「まだ仕様が固まっていない業務課題」を、短期間で動く形にして検証する仕事に強みがあります。

## 職務要約

AIを使った開発運用、Webサービス、業務自動化、資料作成、SNS運用、教育コンテンツ、検証環境をまとめて構築してきました。

現在の開発環境には、31件のプロダクト領域、AIエージェント運用基盤、LP・Webデモ、スライド生成、自動投稿、RAG検索、動画制作補助、ブラウザ検証の仕組みがあります。

単に「アプリを作る」だけではなく、要件整理、試作、検証、改善、運用ルール化まで含めて進められます。

## 代表プロジェクト

### 1. AI業務支援・AI開発検証基盤の構築

AIに作業を任せるだけでなく、作業担当、レビュー担当、セキュリティ確認担当、仕様確認担当を分ける開発体制を作りました。

これにより、作った本人が自己採点して終わるのではなく、別の視点で確認する流れを組み込んでいます。AI時代の開発で起きやすい「それっぽいが未検証」の問題を減らすための基盤です。

確認できる成果物:

- AIエージェント定義
- 作業ルール
- 検証担当の分離
- 実行前後の安全チェック
- 開発記録と引き継ぎ用メモ

証拠として確認できる場所:

- `.claude`, `.codex`, `.agents`
- `docs/standards`
- AIエージェント定義 12体
- プロダクトごとの運用メモ 31件

### 2. 業務自動化・投稿自動化ツール

SNS投稿、X投稿、Instagram運用、動画制作補助、CSV生成、画像差し替え、音声解析など、手作業で繰り返す業務を自動化する仕組みを作っています。

人が毎回判断しなくてよい作業を切り出し、スクリプトや運用ツールに置き換えることで、作業時間の短縮とミスの削減を狙っています。

確認できる成果物:

- X投稿支援
- Instagram運用支援
- YMM動画制作補助
- 日次運用スクリプト
- 投稿・分析・レビュー用データ

証拠として確認できる場所:

- `products/x-auto-post`
- `products/instagram-auto-ops`
- `products/ymm-shorts`
- `scripts` 約60ファイル

企業サイト、サービス紹介ページ、Webデモ、予約・管理系画面、学習アプリなどを複数制作しています。

見た目だけのページではなく、フォーム、管理画面、学習機能、検証用デモ、営業用デモなど、実際の提案や業務検証に使える形で制作しています。

- Webアプリ試作

AI講座、営業提案、教育コンテンツ、HTMLスライド、PPTX、Google Slides生成など、資料作成のための仕組みと成果物があります。

1回限りの資料作成ではなく、テンプレート化・自動生成・再利用を前提にした制作環境を整えています。

## 現時点で補足が必要な点

この経歴書では、売上、ユーザー数、商用サービスの本番運用年数、チーム開発人数などの数値実績はまだ提示していません。

そのため、大規模SaaSの中核バックエンド、金融・医療・基幹系の本番運用責任者、テックリードとしての採用には、追加でコード、デモURL、運用実績、障害対応実績の提示が必要です。
