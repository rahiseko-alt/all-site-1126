## メールテンプレート4類型

SaaSプロダクトで必要なメールは以下の4種に大別できる。各プロダクトで必要なものを選んで実装する。

### 1. ウェルカムメール（自動送信）

| 項目 | 内容 |
|------|------|
| トリガー | ユーザー登録直後 |
| 送信先 | 登録メールアドレス |
| 必須コンテンツ | ダッシュボードURL、はじめかた（3ステップ以内）、問い合わせ先 |
| 目的 | 初回ログイン率を上げる。登録→放置を防ぐ |

### 2. フォローアップメール（手動 or 条件トリガー）

| 項目 | 内容 |
|------|------|
| トリガー | ウェイトリスト登録 / 問い合わせ / N日間未ログイン |
| 送信先 | 対象者メールアドレス |
| 必須コンテンツ | 利用開始URL、利用手順、無料であること（該当する場合） |
| 目的 | 見込み客→アクティブユーザーへ転換 |

### 3. 管理者通知メール（自動送信）

| 項目 | 内容 |
|------|------|
| トリガー | ユーザー登録 / 問い合わせ / エラー発生 |
| 送信先 | マスターのメールアドレス（環境変数 `MASTER_EMAIL`） |
| 必須コンテンツ | イベント種別、ユーザー情報、タイムスタンプ |
| 目的 | ユーザー動向のリアルタイム把握。初期段階のトラクション監視 |

### 4. 自動返信メール（自動送信）

| 項目 | 内容 |
|------|------|
| トリガー | 問い合わせフォーム送信直後 |
| 送信先 | 問い合わせ者メールアドレス |
| 必須コンテンツ | 受付確認、返信期限の案内（例: 2営業日以内） |
| 目的 | 「ちゃんと届いた」安心感。放置されていない印象 |

## 実装ガイドライン

| 項目 | 指針 |
|------|------|
| メール送信サービス | Resend / SendGrid / SES。Vercel Serverless経由でプロキシ |
| APIキー管理 | 環境変数（`RESEND_API_KEY` 等）。クライアントコードに含めない |
| 送信元アドレス | カスタムドメイン推奨（到達率向上）。環境変数 `EMAIL_FROM` |
| テスト | ローカルではコンソールログ出力 or Resend テストモード |
| エラーハンドリング | 送信失敗時はリトライ1回 + 管理者通知。ユーザー操作はブロックしない |

## プロダクト側の使い方

1. 本テンプレートをコピーして `products/{product}/docs/delivery-template.md` を作成
2. 4類型から必要なものを選択
3. プロダクト固有のコンテンツ（URL、手順、ブランド名）を記入
4. 実装ファイルパス（例: `src/lib/email.ts` → `sendWelcomeEmail()`）を追記
