# .impeccable.md — vibe-base Design Context

## Design Context

### Users
- **BtoB（管理画面・SaaSツール）:** 中小企業・個人事業主。業務中にストレスなく使いたい。信頼と効率を求める
- **BtoC（LP・フード・ライフスタイル）:** 一般消費者。感情的な共感と行動喚起を求める
- **開発者向けツール:** エンジニア。速度・明快さ・技術的正確さを求める

### Brand Personality
プロダクトの性格によって使い分ける（固定しない）:

| プロダクト種別 | 3語 | 代表例 |
|-------------|-----|--------|
| BtoB管理画面・SaaS | 信頼・シンプル・プロ | AI Answer, kobaraku |
| LP・マーケティング | 洗練・大胆・現代的 | （該当なし） |
| フード・ライフスタイル | 温かみ・親しみ・使いやすさ | foodee |
| 開発ツール・ダッシュボード | ミニマル・高速・技術的 | microscope |

### Aesthetic Direction
- **テーマ:** ライトモードのみ
- **ベースカラー:** #f8fafc（背景）/ #1e293b（テキスト）/ #2563eb（プライマリ）
- **フォント:** Noto Sans JP + Hiragino（日本語）/ Inter・system-ui（欧文）
- **スペーシング:** Tailwind v4 ベース
- **アンチリファレンス:** 装飾過多・KPIカードのカラーアイコン・ネオン系・過剰なシャドウ

### Design Principles
1. **ストレスゼロ** — 目線と指の移動を最小化。ボタンを増やすな、UXが悪化する
2. **開発用語排除** — UIに技術用語を露出しない。エンドユーザーに伝わる言葉だけ使う
3. **プロダクト性格に忠実** — 汎用デザインを避ける。BtoB管理画面をLPっぽくするな
4. **シンプルが先** — 装飾は機能の邪魔をしない範囲でのみ許可
5. **アニメーションは意味を持つ** — 動かすだけのアニメーション禁止。ユーザーの認知を助けるものだけ

### Tech Stack
- React 19 + Vite + Tailwind CSS v4
- shadcn/ui（一部プロダクト）
- Vercel（デプロイ）
- Supabase（DB/Auth）
- Framer Motion / CSS Animations（アニメーション）
- Remotion（動画制作）

### Animation Guidelines
- **タイミング:** 入場100〜300ms / フィードバック50〜150ms / ページ遷移200〜400ms
- **イージング:** ease-out（入場）/ ease-in-out（遷移）/ spring（インタラクション）
- **必須対応:** prefers-reduced-motion を全アニメーションに適用
- **禁止:** 意味のないループアニメーション・注意を奪うモーション
