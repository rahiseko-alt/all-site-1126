# 運用・納品テンプレート集 v1.0

> **PCサイクル P2 #23-24（手順書作成・納品テンプレート）で使用するテンプレート集。**
> プロダクト内の `docs/` にコピーして使う。
> 出典: review-analysis（プロビジョニングガイド）、aiueo/app（運用マニュアル）、microscope（PH Launch）

### これは何か

お客さんに商品を渡すときの「渡し方マニュアル」の雛形集。ソフトウェアは作っただけでは使えないので、「アカウントの作り方」「使い方の説明書」等をセットで渡す必要がある。レストランの開店準備キット（メニュー表の雛形、スタッフ研修資料の雛形）のようなもの。

### 5W2H

| 項目 | 内容 |
|------|------|
| **What** | 納品時にクライアントへ渡す書類（セットアップ手順・操作マニュアル・PH Launch）の雛形3種 |
| **Why** | 納品のたびにゼロから書くと抜け漏れが出る。雛形をコピーすれば品質が安定する |
| **Who** | エージェントがコピーして記入 → マスターが確認 → クライアントに渡す |
| **When** | P2（販売準備フェーズ）の#23-24タスク（手順書作成・納品テンプレート） |
| **Where** | vest1: docs/standards/templates/onboarding.md → 各プロダクトの docs/delivery/ にコピー |
| **How** | 3種のテンプレ（①セットアップ手順 ②操作マニュアル ③PH Launch）をコピー → 記入 |
| **How much** | 1種あたり30分〜1時間。全3種で半日 |

## 2. 運用マニュアルテンプレート — P2 #24

エンドユーザー向けの操作マニュアル。専門用語を排除し、実際の操作手順だけを書く。

```markdown
# {プロダクト名} 運用マニュアル

## 1. はじめかた
1. {URL}にアクセス
2. {ログイン方法}
3. {最初にやること}

## 2. ロールと画面
| ロール | できること | 主な画面 |
|--------|----------|---------|
| {ロール名} | {操作一覧} | {画面名} |

## 3. {ロールA}の操作
### {操作1}
1. {手順}
2. {手順}

### {操作2}
（同形式）

## 4. 初期設定（管理者のみ）
| 設定項目 | 説明 | デフォルト値 |
|---------|------|-------------|

## 5. トラブルシューティング
| 症状 | 原因 | 対処法 |
|------|------|--------|
| {画面が表示されない} | {ネットワーク接続} | {Wi-Fi確認} |

## 6. URL一覧
| 名前 | URL | 用途 |
|------|-----|------|
```

### 運用マニュアルの鉄則

- **開発用語禁止。** 「API」「認証」「トークン」等は使わない
- **画面名で説明。** 「ダッシュボードの右上の歯車マーク」のように具体的に
- **ロール別に分離。** 全操作を1セクションに詰めない
- **トラブルシューティングは症状→原因→対処法の3列。** 症状はユーザーの言葉で書く
