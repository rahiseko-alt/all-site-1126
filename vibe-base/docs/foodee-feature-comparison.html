差別化機会

  • AI+パーソナライズの空白地帯は完全に未開拓。競合6社中AI機能を持つサービスはゼロ
  • 月刊誌（食堂/近代食堂）は深いが遅い。Webメディア（飲食店.com/hibana/フーズCH）は速いが浅い。foodeeは「深い×速い」を狙える
  • 飲食店.comは総合プラットフォーム。情報メディアは集客ファネルに過ぎず、情報品質に本気投資していない
  • 月刊誌の読者はデジタル移行の潜在需要あり（月刊食堂アプリ版が存在する=需要の証拠）
  • 競合メディア自体をRSSソースとして取り込む戦略（H8）。飲食店.com/hibana/フーズCH/テンポスのRSSをfoodeeに集約すれば、競合がfoodeeのコンテンツ供給源になる。ユーザーは個別メディアを知らなくてもfoodeeだけで済む構造
