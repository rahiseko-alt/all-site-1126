## スコープ
- **ココナラ:** 売上・閲覧数・お気に入り・問い合わせ等の販売データ分析
- **GA4:** 全6プロパティのUU/PV/流入元/CV等のアクセスデータ分析
- **横断分析:** プロダクト間の比較・トレンド・相関

## フォルダ構成
```
analysis/
├── CLAUDE.md        ← 本ファイル
├── scripts/         ← 分析・集計スクリプト
├── data/            ← 取得・加工済みデータ（.gitignoreで大容量ファイル除外）
└── reports/         ← 分析結果レポート（HTML推奨）
```

## ルール
1. GA4データは外部トラフィックのみ集計（direct/localhost/not set/自サイト間遷移は除外）
2. 数値はデータの中央値・最頻値の実数で報告。平均値のみの報告は禁止
3. レポートはHTML形式で `reports/` に保存（マスターがブラウザで確認できる形式）
4. `data/` 内の生データはコミット前にサイズ確認。10MB超はgitignore対象
5. 分析結果から行動提案を出す場合、根拠となるデータのパスを必ず明記
