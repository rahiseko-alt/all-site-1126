Aiueo UI設計方針案

競合調査結果に基づく、Aiueo各画面のデザイン方向性の提案です。

レジ画面 — 設計方針

  • 2カラム構成: 左=商品グリッド（カテゴリ色分けタイル） / 右=カート+合計+支払いボタン
  • 白背景 + Aiueoブランドカラーのアクセント（業界標準に準拠）
  • 合計金額を最大フォントで表示。金額の視認性が最優先
  • 「支払いへ進む」ボタン: 画面最下部、ブランドカラー、金額表示付き
  • カテゴリ色分け: タイルの背景色でカテゴリを識別（Airレジ方式）
  • 参考元: Airレジ（シンプルさ・4モード切替）+ Square（グリッドの自由度）

KDS画面 — 設計方針

  • カード型グリッド: FreshKDSのTiled Viewがベスト（情報密度と視認性のバランス）
  • ダークモード基本: 背景 #1a1a2e、カード #252840（キッチン環境の標準）
  • 信号機方式: ヘッダー色で経過時間表現（緑→黄→赤）。全競合共通のパターン
  • 大フォント・高コントラスト: キッチンでは1m以上離れて見る前提
  • タップ1回で完了: FreshKDS方式。最もシンプル
  • モディファイア強調: 赤テキスト + 太字（Toast方式）

管理画面 — 設計方針

  • 左サイドバー + メインコンテンツ: Square/スマレジの標準パターン
  • ダッシュボード最上部にKPIカード: 本日売上・取引数・客単価（3枚）
  • 時間帯別売上グラフ: 飲食店で最も使われる分析切り口
  • シンプルなメニュー管理: テーブル形式のCRUD
  • 参考元: Airレジ（親しみやすさ）+ Square（ウィジェットの柔軟性）
