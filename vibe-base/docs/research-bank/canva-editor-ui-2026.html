Canva エディタ UI/操作モデル 調査

スマホ PWA 名刺メーカー設計のための「オブジェクト指向編集」作法。Canva 主・Adobe Express / ラクスル比較

調査日: 2026-06-21
調査軸: UI/操作モデル
対象: Canva（主）/ Adobe Express / ラクスル
タグ: ui editor
関連プロダクト: meishi-maker
再利用: キャンバス系エディタUI設計 / オブジェクト選択・ドラッグ・スナップ / 文脈ツールバー / タッチ編集
結論: Canva の核心は「全要素がオブジェクトで、選択→ドラッグ移動→隅ハンドルでリサイズ→スマートガイドでスナップ」＋「選択対象で中身が変わる文脈ツールバー」。名刺は要素が少ない（テキスト数個＋画像1＋QR3）ので、この核心だけ取り込めば素人体験は跳ねる。フル Canva は過大。

A. 画面構成（3領域＋文脈ツールバー）確信度 高

  • 左パネル（モバイルは下部フッター）= タブ式ツールボックス: テンプレ / 素材(Elements) / アップロード / テキスト / 写真
  • 中央 = キャンバス（作業領域）
  • 上ツールバー = 文脈依存: 選択対象で中身が変わる（テキスト→フォント/サイズ/色/間隔/配置、画像→画像操作、背景→背景）
  • 選択要素の直上にフローティングツールバー（複製/削除/ロック/Position 等）

B. 要素操作モデル（オブジェクト指向）確信度 高

  • 全要素が「オブジェクト」: タップ/クリックで選択、ドラッグで移動
  • リサイズ: 四隅ハンドルをドラッグ（等比）。テキストは「隅ドラッグ=フォントサイズ」「左右ピルハンドル=ボックス幅」
  • 回転: 回転ハンドル
  • テキスト編集: ダブルクリック/ダブルタップで編集モード
  • スマートガイド: 紫の点線で整列を可視化しスナップ。Ctrl 押下で一時無効

C. 整列・重なり・グループ（Position）確信度 高

  • Position: 重ね順（前面/背面）、ページ整列、複数選択時の要素間整列・等間隔分配
  • レイヤーパネル: ドラッグで重ね順変更
  • グループ: Shift 複数選択 → Group（Ctrl+G）でまとめて操作
  • ロック: 位置ロック（サイズ/色は編集可）

D. テンプレート起点 確信度 高

白紙でなくテンプレ選択から開始し、テキスト差し替え・画像配置で完成。ラクスルも同型（テンプレ→編集→「仕上がり確認」→入稿/購入の一本道）。

E. モバイル/タッチ（本製品の本命）確信度 中〜高

  • タップ選択＋ドラッグ移動、隅ドラッグで等比リサイズ
  • 操作系は下部ツールバー（フッター）に集約（position/arrange 等）
  • ピンチズーム（キャンバス拡大）
  • ダブルタップによるテキスト編集の公式明記は未確認（出典未確定）

F. Adobe Express 比較 確信度 中

よりクリーンで雑然としない UI、ワンクリック「クイックアクション」、レイヤー対応、1 テキストボックス内で複数フォントスタイル。Canva は「直感的・ドラッグ＆ドロップ」が代名詞。

So-What（meishi-maker への適用）

  1. オブジェクト選択モデル（キャンバス要素をタップ選択）
  2. 選択要素の文脈ツールバー（サイズ/色/フォント/整列）
  3. ドラッグ移動＋スマートガイド/スナップ（塗り足し・セーフエリアへスナップ＝入稿品質に直結）
  4. タッチ最適化（下部ツールバー・ピンチ）
現プロトタイプは「固定グリッドにフォーム入力を流し込む」型で、上記核心（選択して直接操作）が欠落。要素数が少ない名刺なら限定オブジェクト編集（選択・ドラッグ・スナップ・文脈ツールバー）で十分。追加/削除/回転は当面入れない。
