### 判明した Buffer API 要点（routine 構築で必要・保存）

- エンドポイント `https://api.buffer.com` / `Authorization: Bearer <token>`
- 作成: `createPost(input:{ text, channelId, schedulingType:automatic, mode, assets:[], saveToDraft })` → `PostActionPayload` union（`PostActionSuccess{post{id status text}}` / 各種 Error{message}）
- `mode` enum: `addToQueue`（キュー末尾）/ `shareNext`（先頭）/ `shareNow`（即時）/ `customScheduled`
- 無人配信は `saveToDraft` を外し `mode:addToQueue`
- 確認: `post(input:{id}) { id status text }` / 削除: `deletePost(input:{id})` → `DeletePostPayload`（`DeletePostSuccess{id}` / `VoidMutationError{message}`）
