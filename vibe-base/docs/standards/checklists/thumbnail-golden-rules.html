⚡文字数上限
サムネイル内のテキストは 15〜20文字 が上限。それ以上は読まれない。
Fiverrのトップセラーは 5語以下（英語基準）。日本語換算で10〜15文字。
⚡要素数は2つまで
「情報を詰め込む」は逆効果。伝えたい要素は 最大2つ に絞る。
0.3秒では3つ伝えても1つしか届かない。2つ目は「補足」として認識される程度。
⚡フォントサイズ
メインコピー: 300pt以上。補足テキスト: 100pt以上。
フォントは太め（Bold/Black）。細いフォントはスクロール中に消える。
フォントの種類は 2種類まで。3種以上は散らかる。

🎨高CTR配色
CTRが高い背景色: 白 ピンク 青
赤は「進出色」→ 緊急性・行動喚起に強い。CTAボタンやセール情報に最適。
青は信頼感・安定感 → 金融・専門サービスに効果的。
配色は 3色まで: ベースカラー + メインカラー + アクセントカラー（補色）
👀視線誘導（Z型の法則）
人の目線は 左上 → 右上 → 左下 → 右下 に流れる（Z型）。
左上にキャッチコピー、右下にCTA/価格を配置すると自然に誘導できる。
バナーに最も使われるレイアウトパターン。

ブロック構成とグーテンベルク・ダイアグラム
全プラットフォーム共通
📜ブロック数の上限
バナー/サムネの情報ブロックは 最大3つ。
「画像 + ヘッドライン + CTA（またはロゴ）」の3点構成が鉄則。
3要素に絞った場合、CVR 最大40%向上 のデータあり。
ミラーの法則（7±2）はリスト記憶の話であり、一瞬で走査するサムネには適用しない。サムネは3が上限。
📈グーテンベルク・ダイアグラム（4象限モデル）
Z型視線誘導の根拠となるモデル。画面を4象限に分割する:

第1象限: Primary Optical Area（左上）
視線の起点。最も注目される。
→ ヘッドライン/メインコピーを置く 		第2象限: Strong Fallow Area（右上）
起点から自然に流れて到達。
→ サブ情報/ビジュアルを置く
第3象限: Weak Fallow Area（左下）
最も注目されない死角
→ 重要情報を置くな。空けるか弱い補足のみ 		第4象限: Terminal Area（右下）
視線の終着点。行動決定点。
→ CTA/価格を置く
視線の流れ: 第1 → 第2 → 第3を飛ばして → 第4（Z字）
🛠ブロック配置ルール（Z型の正しい使い方）
3ブロック構成の場合の配置:
・第1象限（左上）: ヘッドライン — 最重要情報。2〜3行以内に収める
・第2象限（右上）: ビジュアル/実物提示 — 視線が水平移動で到達
・第4象限（右下）: CTA/価格 — 対角線移動で到達する終着点
・第3象限（左下）には重要ブロックを置かない

ヘッドラインが第1象限からはみ出して第3象限に侵食すると、Z型動線が崩壊する。
各ブロックは割り当てられた象限内に収めること。

2階層の視線動線（マクロ/ミクロ）
全プラットフォーム共通
🌎マクロレベル（ブロック間）
画面全体をZ型で走査。どのブロックをどの順番で見るかを制御する。
第1象限→第2象限→第4象限の順で視線が移動。
ブロック間の距離・サイズ差・コントラスト差で誘導を強化できる。
🔍ミクロレベル（ブロック内）
各ブロック内部も 左上→右下 で読まれる（ミニZ）。
ブロック内の要素数は少ないほど認知負荷が下がる。
関連する要素は近くに（近接の法則）、関係ない要素は離す → ブロックの「塊」が自然に認識される。
⚠象限侵食の禁止
1つのブロックが複数の象限にまたがると、Z型動線が崩壊する。
例: ヘッドラインが6行で第1象限（左上）から第3象限（左下）まで侵食 → 視線がZ型で動かず縦読みになる。
各ブロックは1象限に収めるのが原則。

現サムネイル（v3）の診断

文字数
約80文字 — 基準の4倍以上。痛み文2行+ヘッドライン2行+サブコピー+チャット内テキスト
要素数
9個以上 — 痛み / ヘッドライン / サブコピー / チャットモック / ピル4つ / 価格バッジ
フォント
サイズ不足 — メインコピーが86px。300pt基準に対して大幅に不足
Z型配置
中央揃え — Z型視線誘導になっていない。全要素が縦積みセンタリング
3秒テスト
不合格 — 0.3秒で「何のサービスか」が伝わらない。情報過多で視線が散る
黄金律に基づく修正方針
1. 文字を 15〜20文字 に削減（メインコピー1行 + サブ1行のみ）
2. 要素を 2つ に絞る（コピー + チャットモック or コピー + 価格）
3. メインフォントを 300pt+ に拡大
4. Z型レイアウト に変更（左上=コピー、右下=価格）
5. ピル4つ・痛み文・サブコピーは全て 削除（紹介画像に回す）
