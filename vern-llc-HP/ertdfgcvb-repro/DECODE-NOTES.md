## js.js プログラム部の解読結果（本体プログラム）
エンジンへの渡し値: 出力先は `<pre>`、**fps 60**、userData は URL 由来の `{word, mode, color}`。
- `?mode=screensaver` でメニュー重ね描きを無効化
- `?color=white` で白系固定、`?color=` その他でカラー循環、無指定でポインタ連動
- `#<3文字>` または `?word=` でテクスチャの単語を固定

### テクスチャ（背景の正体）
- 8×11 のビットマップフォント（A–Z, 0–9 をビット列で保持）で **3文字単語** を描いた 24×11 の二値テクスチャ
- 単語は **300フレームごと** に切替。先頭は ERT → DFG → CVB（サイト名の分割）、以後はシャッフル済み3文字単語辞書を巡回
- 切替時は文字が1文字ずつ **6フレームずつずれて**、奇数フレームにだけ文字セットを1つずつ送るスプリットフラップで入れ替わる

### pre（毎フレームの前処理）
- 値ノイズ（256 permutation + smootherstep 補間）でテクスチャ座標を歪曲: x方向 0.5 倍、y方向 1.8 倍
- ノイズのスケール係数は cos(time × 0.0004) を 1.2〜0.5 に remap した「呼吸」
- テクスチャの拡縮率は画面比に合わせ、0.8（幅80セル未満では1.3）へ 0.01/フレームで追随
- セル値は max( bilinear サンプル, ハードピクセル )
- ポインタ速度から: 光半径² = min(半径²×0.75 + 0.4×速度, 20)、活動量 = 速度>0.1 で +0.008/フレーム、減衰 −0.003/フレーム
- 色: 活動量 0.3〜0.8 を smootherstep で 0..1 にし、グレー2色 rgb(120,120,120) / rgb(90,90,90) から、9色パレット（#00AAAA, #AA0000, #AA5500, #5555FF, #55FF55, #55FFFF, #FF5555, #FF55FF, #FFFFFF）からランダムに選んだ2色へ補間。活動量が 0.3 未満の間に次の色ペアを抽選
- ランプ末尾の特殊記号ペアは、活動量が 1 に達した時（または screensaver で 3000フレームごと）に次のペアへフラップ遷移

### main（セルごと）
- 表示値 i = max(テクスチャ値, 前フレーム値)、その後 **v = 0.95 × i**（残像減衰）
- 文字は2種の濃淡ランプを (x+y) の偶奇で市松に切替、index = floor(i × (len−1))
- 色は i ≥ 0.99 のセルのみ「熱い」側の色、それ以外は通常色
- ポインタ近傍（距離² < 半径²）のセルはフラップ開始位置とフラップ中フラグをセット → post でメニュー文字が再フラップする（＝カーソルで文字がパラパラする仕組み）

### boot（初期化）
- セルのフラップ遅延 = floor(x/3 + 2y) + 2 → 起動時にメニュー文字が斜めにフラップしながら現れる

### post（メニューの重ね描き）
- 不可視の main div 群を実測（セル単位の x/y/幅）し、テキストをカラム幅で折り返してバッファへ書き込む
- リンクはセルの beginHTML/endHTML で <a> として再構成（クリック可能）。`data-flap=1` のリンク（tiroir 挨拶）だけ常時フラップ対象
- 区切り: cols モードでは各カラム左に `│` を全高、rows モードでは各ブロック上に `─`
- フラップ状態機械: counter > 1 の間はカウントダウンしながら記号テーブルを表示、= 1 では目標文字に一致するまで記号を送り続ける
- 'f' キーでフルスクリーン
