## 🔴 最重要

1. **Instagram が復活した（実測）。** 5チャンネル全て `PostActionSuccess`（X2・Threads2・**IG1＝動的生成画像つき**）。07-20 昼のプロンプト刷新以降スキップされ続けていたが復旧。キャプションと画像テーマの一致も確認済。

2. **「環境変数を設定すれば動く」は誤りだった。構造欠陥が2つ重なっていた。**
   - **A（秘匿情報）**: cloud environment には環境変数欄しかなく値は平文で常時表示。UI 自身が「シークレットを追加しないでください」と警告する場所に `BUFFER_API_TOKEN` が平置きされていた。ここに OpenAI キーを足すのは漏洩面を増やすだけ。
   - **B（到達不能）**: 旧設計は生成画像を `buffer-refill` に push し raw URL で配信する前提だったが、**同リポは PRIVATE で raw URL は 404**（実測）。環境変数を直しても自己検証GETが失敗し IG は永久にスキップされる構造だった。

3. **解決: 画像生成を GitHub Actions へ分離、画像だけ公開リポで配信。cloud environment に OpenAI キーは置いていない。**
   ```
   11:30 JST  GH Actions（rahiseko-alt/ig-images・PUBLIC / キーは GitHub Secrets）
                └ 画像生成 → images/ig-YYYYMMDD.jpg + latest.json を commit
   12:03 JST  buffer-refill routine
                └ latest.json を GET し imageUrl を Buffer に渡すだけ（生成しない）
   ```

4. **Buffer トークンが本作業中に露出した。** 設定画面を開いた際に平文表示されスクショに写り込んだ。マスターが新キーへ差し替え済（実機テスト成功＝新トークン有効）。**旧キー `kosehira-cli` の Revoke は別セッション（worktree `claude/wonderful-bhaskara-ea2cf6`）で進行中。**
