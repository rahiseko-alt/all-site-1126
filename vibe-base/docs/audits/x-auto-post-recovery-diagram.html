③ 何が・なぜ止まったか（3つの故障が連鎖）

故障1・根因
補充のLLMキー欠落
GitHub secret の XAUTOBOT260616_GEMINI/_GROQ/_GHMODELS が3件とも不在。generate.py が本文を作れず0件。
故障2・隠蔽
サイレント成功
0件でも EXIT 0=「成功」表示。5日間、緑のまま裏で崩壊。誰も気付けなかった。
故障3・枯渇
在庫ゼロ→投稿停止
補充されないまま在庫を消費し尽くし、投稿する弾が無くなった（現在 残0）。
重要 monitor（検知）は正しく動作し Issue #43〜#46 を起票済み。だが GitHub Issue がマスターに届かず放置された ＝ 「検知はできても通知が届かない」設計欠陥。これが再発防止の本丸。
