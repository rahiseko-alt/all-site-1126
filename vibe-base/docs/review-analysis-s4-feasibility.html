競合との技術選択の差異

  • AWS vs Vercel: 競合3社はAWSを使用。自社はVercel。理由: 開発コスト¥0制約。VercelのHobbyプランは無料、AWSは従量課金で¥0保証が困難
  • GBP API vs Places API: 競合は全社GBP API (旧My Business API)を使用。自社はPlaces API (New)。GBP APIはビジネスオーナー認証が必要で、ユーザーにOAuth認証を求める。Places APIは公開クチコミを取得するだけなのでUXが簡素
  • マルチサイト vs Google特化: 口コミコム(31サイト)とGyro-n(Yext30サイト)は多サイト対応。自社はGoogle Maps 1サイト特化。理由: MVPスコープを最小化。Google Mapsが飲食店クチコミの最大プラットフォーム
  • Gemini vs OpenAI/Vertex: 口コミコムはVertex AI+OpenAI。自社はGemini 2.5 Flash単体。理由: 無料枠が最も大きい（15RPM/1500RPD）。日本語性能も十分

差異競合の選択自社の選択なぜ違うかリスク

差別化として狙える競合未使用の選択肢

  1. Gemini無料枠の活用: 競合はAIコストを価格に転嫁（¥7,000〜¥55,000/月）。自社はGemini無料枠で¥0/月を実現 → 価格破壊の源泉
  2. Vercel Edge Functions: 競合はAWS EC2/Fargate（常時起動）。自社はEdge Functions（コールドスタート不要、東京リージョン） → レスポンス速度で差別化
  3. Places API（認証不要）: 競合はGBP APIのOAuth認証を前提。自社はPlaces APIで「店名入力だけで即分析開始」→ UX簡素化(H12対応)
