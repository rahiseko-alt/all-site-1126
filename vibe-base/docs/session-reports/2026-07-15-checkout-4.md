### Buffer API レシピ（次セッション再利用）
- endpoint `https://api.buffer.com` / `Authorization: Bearer <token>`
- 一覧: `channels(input:{organizationId})` / `posts(input:{organizationId, filter:{channelIds,status}}, first)` → `edges{node{id status text}}`
- 作成: `createPost(input:{text, channelId, schedulingType:automatic, mode:addToQueue, assets:[], metadata})` → PostActionSuccess/各Error union
- 画像: `assets:[{ image:{ url: "<公開URL>" } }]`（url は NON_NULL・Buffer が取得。**外部Vercel URL でも受理された**）
- Instagram 必須: `metadata:{ instagram:{ type:"post", shouldShareToFeed:true } }`（PostType enum: post/reel/story/carousel...）
- 削除: `deletePost(input:{id})` → DeletePostSuccess
- キュー満タン時: `LimitReachedError`（無料プラン予約10件上限＝Buffer側が自動で弾く。こちらに上限制御不要）
