# 抽出者メモ

- v1.0 → v3.0 のあいだ、約2週間で **14回** 改訂されている。1日2リリースの日も普通にある（v1.5/1.6/1.7 が同日、v1.9/v2.0 が同日、v2.2/v3.0 が同日）
- 改訂の引き金は3パターンに大別できる:
  1. **運用事故:** v1.1（容量逼迫）/ v1.3（UAT 空転）/ v1.4（仲介作業発覚）
  2. **観察された改善余地:** v1.5（AG が逸脱する→マイクロタスク化）/ v2.1（デプロイ忘れ→完了の定義）
  3. **構造改革:** v3.0（466行→120行リファクタ＋メタルール新設）
